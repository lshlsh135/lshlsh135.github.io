Claude Code v2.1.129가 나왔는데 플러그인·터미널·게이트웨이 쪽에서 실용적인 옵션들이 늘었어요. 새로 들어온 `--plugin-url <url>` 플래그로 현재 세션에 한해 URL에서 플러그인 .zip을 받아 쓸 수 있고, Emacs eat처럼 자동 감지에 걸리지 않는 터미널을 위해 `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` 환경변수로 동기 출력을 강제할 수 있습니다. Homebrew·WinGet 설치 환경이라면 `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`를 켜두면 백그라운드에서 업그레이드를 돌리고 재시작 프롬프트를 띄워줘요. 동작 변경도 있는데, 플러그인 매니페스트의 themes·monitors는 이제 `"experimental": { ... }` 아래에 선언하는 게 권장이고 기존 톱레벨 선언은 `claude plugin validate`에서 경고가 뜹니다. 그리고 2.1.126~2.1.128에서 자동으로 켜졌던 `/model` 피커의 게이트웨이 `/v1/models` 자동 발견은 이제 `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` 옵트인으로 바뀌었고, Ctrl+R 히스토리 피커는 다시 2.1.124 이전처럼 전체 프로젝트의 프롬프트를 기본 검색하며 Ctrl+S로 현재 프로젝트/세션만 좁힐 수 있어요(서드파티 배포 관련 변경은 EXCERPT가 잘려서 본문 확인 필요).
