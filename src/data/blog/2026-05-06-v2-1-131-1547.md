이번 v2.1.131 패치는 두 가지 버그 수정 위주의 릴리스예요. 첫째, Windows에서 VS Code 확장이 활성화되지 않던 문제를 고쳤는데, 번들된 SDK의 createRequire 폴리필에 빌드 경로가 하드코딩돼 있던 게 원인이었다고 해요. 둘째, Mantle 엔드포인트 인증이 x-api-key 헤더 누락으로 실패하던 문제도 함께 수정됐어요. 새 기능 추가는 없고, Windows에서 확장 활성화가 막혔거나 Mantle 인증 실패를 겪던 사용자라면 바로 업데이트할 가치가 있는 패치입니다.
