Claude Code v2.1.132에서 환경변수 두 개가 새로 추가됐어요. Bash 도구 서브프로세스에 훅으로 전달되는 session_id와 동일한 값이 담긴 CLAUDE_CODE_SESSION_ID가 노출되고, CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1을 켜면 풀스크린 대체화면 렌더러를 끄고 대화를 터미널 기본 스크롤백에 그대로 남길 수 있어요. UX 쪽에선 Ctrl+V로 이미지를 붙여넣을 때 클립보드 읽는 동안 "Pasting…" 푸터 힌트가 표시되도록 바뀌었습니다. 버그 수정도 꽤 많은데, IDE 정지 버튼이나 kill -INT로 외부 SIGINT가 들어왔을 때 graceful shutdown이 돌지 않고 그냥 끊기던 문제가 고쳐져서 이제 터미널 모드가 복구되고 --resume 안내까지 출력돼요. 네이티브 빌드에서 세션 도중 터미널이 닫히거나 SSH가 끊길 때 발생하던 uncaught exception, 도구 에러 truncation이 이모지를 둘로 쪼개버려 --resume이 "no low surrogate in string"으로 실패하던 문제(이미 깨진 세션도 로드 시 자동 정리)도 잡혔습니다. 마지막으로 -p --continue/--resume로 플랜 모드 세션을 이어받을 때 --permission-mode 플래그가 무시되고 ExitPlanMode 후 플랜 모드가 다시 적용되지 않던 동작도 수정됐어요.
