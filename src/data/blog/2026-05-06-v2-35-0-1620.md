OpenAI 관련 SDK/CLI로 보이는 저장소의 v2.35.0 릴리스(2026-05-06)다. Features에는 api 쪽 image 2 업데이트(0ba55d7)와 수동 업데이트(72bf67a)가 포함됐다. Chores로는 legacy python cli 제거(32f36e4)와 legacy python cli 엔트리포인트 이름 변경(a3b182d)이 들어가, 기존 파이썬 CLI를 쓰던 사용자에게는 호환성 영향이 있을 수 있는 정리 작업이 진행됐다. Documentation에서는 chat과 responses 양쪽에서 top_logprobs 파라미터 설명이 갱신됐다(f9d339f). 입력에 본문이 없어 구체 변경 범위·마이그레이션 가이드는 v2.34.0...v2.35.0 전체 changelog에서 직접 확인하는 편이 안전하다.
