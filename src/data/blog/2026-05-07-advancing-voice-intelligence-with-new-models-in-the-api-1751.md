OpenAI가 API에 음성을 추론·번역·전사할 수 있는 새로운 실시간(realtime) 음성 모델을 추가했어요. 단순 STT/TTS를 넘어 대화 흐름 안에서 사고하고 다국어 통역까지 처리할 수 있어, 더 자연스럽고 지능적인 음성 경험을 만들 수 있다는 게 핵심이에요. 음성 에이전트, 실시간 통역, 콜센터/회의 전사처럼 지연 시간이 중요한 사용 사례를 겨냥한 업데이트로 보입니다. 본문이 제공되지 않아 구체적인 모델명·가격·지원 언어 목록은 확인되지 않았으니, 실제 적용 전엔 OpenAI API 공식 문서에서 모델 ID와 latency·요금 정보를 직접 확인하는 게 좋아요.
