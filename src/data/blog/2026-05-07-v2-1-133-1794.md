Claude Code v2.1.133 릴리스에서는 worktree와 sandbox, hooks 관련 설정이 여러 개 추가/변경됐어요. 핵심은 worktree.baseRef 설정(fresh | head)이 새로 생겨서 --worktree, EnterWorktree, 에이전트 격리 worktree가 origin/<default>에서 브랜치할지 로컬 HEAD에서 브랜치할지 고를 수 있게 됐고, 기본값이 fresh라서 EnterWorktree의 base가 다시 origin/<default>로 돌아갔다는 점이에요(2.1.128부터는 로컬 HEAD였음 → 푸시 안 한 커밋을 새 worktree에 가져가려면 worktree.baseRef를 "head"로 바꿔야 함). 그 외 Linux/WSL용 sandbox.bwrapPath·sandbox.socatPath 관리 설정으로 bubblewrap·socat 바이너리 경로를 지정할 수 있고, parentSettingsBehavior admin-tier 키('first-wins' | 'merge')로 SDK managedSettings을 정책 머지에 포함시킬 수 있어요. Hooks는 이제 active effort level을 effort.level JSON 입력 필드와 $CLAUDE_EFFORT 환경변수로 받고 Bash tool 명령에서도 $CLAUDE_EFFORT를 읽을 수 있으며, focus mode 동작 개선과 메모리 압박 시 warm-spare 백그라운드 워커 해제로 메모리 사용량도 개선됐어요. 병렬 세션이 401에서 dead-end되던 버그도 고쳐졌는데 자세한 조건은 EXCERPT가 잘려서 거기까지만 확인 가능해요.
