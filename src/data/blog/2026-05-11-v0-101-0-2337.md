Anthropic SDK가 0.101.0 버전을 2026-05-11에 릴리스했어요. 가장 큰 변화는 AWS 위에서 돌아가는 Claude Platform 전용 AWS 클라이언트가 새로 추가된 것(커밋 1e70e3a)이에요. 버그 수정으로는 파일 타입 에러 메시지에 빠져 있던 f-string 접두어가 보강됐고(06d109a), 잡일 항목으로 tools_runner.py 예제가 claude-sonnet-4-5-20250929 모델로 올라갔으며 예제 shebang이 poetry에서 uv로 교체됐어요. 변경 폭이 크지 않은 점진 릴리스라 AWS 경로를 쓰는 사용자나 예제 코드를 그대로 참고하는 입문자에게 의미가 있어요.
