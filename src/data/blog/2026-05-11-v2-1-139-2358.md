🎯 한 줄 요약: 에이전트 뷰·/goal·/scroll-speed 등 세션 관리와 훅 옵션이 추가된 Claude Code 2.1.139 업데이트.

## 📌 무엇이 바뀌었나
- Agent view(Research Preview): 실행 중/내 입력 대기/완료된 모든 Claude Code 세션을 한 리스트로 보여줌. `claude agents`로 시작하며 docs는 code.claude.com/docs/en/agent-view
- `/goal` 커맨드: 완료 조건을 걸어두면 Claude가 그 조건을 만족할 때까지 턴을 이어서 작업. interactive, `-p`, Remote Control에서 모두 동작하고 경과 시간·턴·토큰을 오버레이로 표시
- `/scroll-speed` 커맨드: 마우스 휠 스크롤 속도를 라이브 프리뷰로 조정
- `claude plugin details <name>`: 플러그인의 컴포넌트 구성과 세션당 예상 토큰 비용 표시
- 트랜스크립트 뷰 단축키: `?`(키보드 단축키), `{`/`}`(유저 프롬프트 사이 점프), `v`(단축키 패널 토글)
- 훅에 `args: string[]`(exec form) 필드 추가 — 쉘 없이 커맨드를 직접 spawn해서 경로 placeholder에 따옴표가 필요 없음
- PostToolUse 훅에 `continueOnBlock` 옵션 — true면 훅의 거절 사유를 Claude에게 돌려주고 작업을 이어감

## 💼 누가 써야 하나
여러 Claude Code 세션을 병렬로 굴리는 사람, 장시간 백그라운드 작업을 자동으로 끌고 가고 싶은 사람, 그리고 훅으로 빌드/린트 게이트를 거는 플러그인·툴체인 운영자에게 바로 도움이 된다.

## ⚠️ 주의사항
Agent view는 아직 Research Preview 단계라 동작이 바뀔 수 있다. 훅의 `args` exec form은 쉘 해석을 건너뛰므로 기존에 쉘 expansion(글롭, 파이프 등)에 의존하던 훅은 호환되지 않으니 마이그레이션 시 주의.
