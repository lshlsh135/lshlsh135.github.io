Claude Code v2.1.140은 Agent 도구의 subagent_type 매칭이 대소문자·구분자에 둔감해져서 'Code Reviewer'도 code-reviewer로 자동 해석되고, 에이전트 색상 팔레트가 새로 바뀌었어요. 버그 수정으로는 disableAllHooks나 allowManagedHooksOnly가 켜져 있을 때 /goal이 무한 대기하던 문제를 명확한 메시지로 바꾸고, 심볼릭 링크된 설정 파일에서 설정 핫리로드가 잘못된 변경 이벤트와 불필요한 ConfigChange 훅을 발생시키던 회귀를 잡았습니다. 또 claude --bg가 백그라운드 서비스 idle-exit 직전에 'connection dropped mid-request'로 실패하던 문제, 엔터프라이즈 엔드포인트 보안이 깔린 머신에서 백그라운드 서비스 시작이 시간 부족으로 실패하던 문제, 원격 managed settings가 401에 재시도하지 않던 문제(이제 토큰 강제 갱신 후 1회 재시도)를 고쳤습니다. 추가로 managed extraKnownMarketplaces 자동 업데이트 정책이 known_marketplaces.json에 저장되지 않던 버그와, 이미 완료 알림을 보내는 백그라운드 작업까지 /loop이 중복 wakeup을 스케줄하던 문제도 정리됐어요.
