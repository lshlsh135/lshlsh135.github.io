Anthropic Python SDK v0.102.0이 2026년 5월 13일 공개됐어요. 새 기능으로는 `BetaManagedAgentsSearchResultBlock` 타입 추가, 캐시 진단(cache diagnostics) 베타 지원, 그리고 내부적으로 pydantic 이터레이터를 즉시(eager) 검증할 수 있게 한 변경이 들어갔습니다. Chores 항목에는 API 스펙 업데이트가 포함돼 있어요. Managed Agents 검색 결과를 다루거나 프롬프트 캐시 동작을 디버깅하려는 SDK 사용자라면 이번 마이너 업데이트를 확인해 볼 만합니다.
