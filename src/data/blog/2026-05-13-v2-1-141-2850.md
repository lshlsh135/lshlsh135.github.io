Claude Code v2.1.141 릴리스 노트입니다. 훅 JSON 출력에 terminalSequence 필드가 추가돼서 컨트롤링 터미널 없이도 데스크톱 알림, 윈도우 타이틀, 벨을 훅에서 띄울 수 있게 됐고, GitHub SSH 키가 없는 환경을 위해 CLAUDE_CODE_PLUGIN_PREFER_HTTPS 환경변수로 플러그인 소스를 HTTPS 클론하도록 강제할 수 있습니다. 워크로드 아이덴티티 페더레이션 쪽으로는 ANTHROPIC_WORKSPACE_ID 환경변수가 추가돼서 페더레이션 룰이 여러 워크스페이스를 커버할 때 발급 토큰을 특정 워크스페이스로 스코프할 수 있게 됐고, claude agents --cwd <path> 옵션으로 세션 목록을 디렉터리 기준으로 좁혀볼 수 있습니다. /feedback이 최근 24시간/7일 세션을 포함할 수 있어서 현재 세션을 넘어가는 이슈도 함께 신고 가능하고, Rewind 메뉴의 'Summarize up to here'로 앞쪽 컨텍스트만 압축하고 최근 턴은 유지할 수 있습니다. 자동 모드 권한 다이얼로그가 permissions.ask 룰 때문에 프롬프트가 떴는지 설명해주고, IDE 연결 시 파일 편집 권한 프롬프트의 'view diff in your IDE' 옵션도 복구됐습니다.
