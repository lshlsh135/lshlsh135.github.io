claude agents 명령에 백그라운드 세션 설정용 플래그가 대거 추가됐어요: --add-dir, --settings, --mcp-config, --plugin-dir, --permission-mode, --model, --effort, --dangerously-skip-permissions. Fast 모드 기본 모델이 Opus 4.6에서 Opus 4.7로 바뀌었고, 4.6으로 고정하고 싶으면 CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1 환경 변수를 설정하면 돼요. skills/ 하위 디렉터리 없이 루트에 SKILL.md만 둔 플러그인도 이제 스킬로 노출되고, /plugin details와 claude plugin details에서 플러그인이 제공하는 LSP 서버 목록을 볼 수 있어요. 버그 수정으로는 원격 HTTP·SSE MCP 서버에서 MCP_TOOL_TIMEOUT 설정과 무관하게 60초로 잘리던 문제, 기존 git worktree를 인식 못 해 EnterWorktree가 중복 생성을 거부하면서 Edit이 막히던 문제, macOS sleep/wake 후 백그라운드 세션이 사라지고 데몬 재연결이 실패하던 문제가 해결됐어요. 그리고 /web-setup이 기존 GitHub App 연결을 덮어쓰기 전 경고를 띄워줘요.
