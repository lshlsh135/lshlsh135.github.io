이번 v2.1.143은 플러그인 의존성 관리와 백그라운드 세션 개선이 핵심이에요. `claude plugin disable`은 다른 활성 플러그인이 대상 플러그인에 의존하고 있으면 이제 거부하고 복붙 가능한 disable-chain 힌트를 보여주며, `claude plugin enable`은 전이 의존성을 강제로 함께 활성화해줘요. `/plugin marketplace` 탐색 창에는 턴당·호출당 예상 토큰 비용이 표시되고, worktree가 곤란한 레포를 위해 `worktree.bgIsolation: "none"` 설정이 추가돼 백그라운드 세션이 EnterWorktree 없이 작업 사본을 직접 편집할 수 있게 됐어요. PowerShell 도구는 이제 기본적으로 `-ExecutionPolicy Bypass`로 실행되며, 끄려면 `CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1`을 설정하면 돼요. 그 외에 백그라운드 세션이 idle 복귀 후에도 모델·effort 레벨을 유지하고, 첨부된 agent 세션의 Shift+Tab 사이클에 auto 모드가 포함됐으며, `.credentials.json`의 scopes 값이 배열이 아닐 때 CLI가 멈추던 문제와 Windows Terminal에서의 우클릭 붙여넣기 버그도 수정됐어요.
