이번 v2.1.144에서는 백그라운드 세션 관리와 터미널 안정성이 한층 다듬어졌어요. `claude --bg`로 시작했거나 agent view에서 띄운 백그라운드 세션도 이제 `/resume` 목록에 `bg` 표시와 함께 나타나고, 백그라운드 서브에이전트 완료 알림에는 '3h 2m 5s' 같은 경과 시간이 붙어요. `/plugin browse`와 discover 화면에서 플러그인의 최근 업데이트 시점을 확인할 수 있고, `/model`은 이제 현재 세션의 모델만 바꾸며 새 세션 기본값으로 지정하려면 모델 선택 화면에서 `d`를 눌러야 해요. 'extra usage' 명칭은 'usage credits'로 정리되어 `/extra-usage`가 `/usage-credits`로 바뀌었는데(구 명령도 그대로 동작), 캡티브 포털·방화벽·VPN 환경에서 api.anthropic.com이 막혔을 때 최대 75초까지 멈추던 시작 지연이 사이드채널 호출 15초 타임아웃으로 해소됐고, VS Code 분할창 드래그처럼 리사이즈 이벤트를 놓쳐 깨지던 터미널 출력이 Ctrl+L 없이도 다음 프레임에서 자동 복구되도록 고쳐졌어요.
