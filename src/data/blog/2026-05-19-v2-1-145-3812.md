이번 v2.1.145에서는 스크립팅·관측성·플러그인 탐색·보안 쪽이 한꺼번에 손봐졌어요. `claude agents --json` 명령이 새로 추가돼서 실행 중인 Claude 세션을 JSON으로 받아올 수 있게 됐는데, tmux-resurrect나 상태바, 세션 피커 같은 외부 도구와 엮어 쓰기 좋아졌습니다. OTEL 쪽에서는 `claude_code.tool` 스팬에 `agent_id`와 `parent_agent_id` 속성이 붙었고, 백그라운드 서브에이전트 스팬이 자기를 띄운 Agent 도구 스팬 아래로 제대로 중첩되도록 트레이스 부모-자식 관계가 고쳐졌어요. 상태줄 JSON 입력에는 감지된 GitHub 리포·PR 정보가 포함되고, `/plugin`의 Discover·Browse 화면이 설치 전에 해당 플러그인의 commands·agents·skills·hooks·MCP/LSP 서버 목록을 보여주게 바뀌었습니다. `claude agents` 터미널 탭 제목에 입력 대기 중인 에이전트 수가 표시돼서 다른 창에 가 있을 때도 누가 손을 기다리는지 알 수 있고, 슬래시 커맨드와 @멘션 자동완성 목록이 풀스크린 모드에서 마우스 호버·클릭을 지원합니다. Stop·SubagentStop 훅 입력에 `background_tasks`와 `session_crons` 필드가 추가됐고, Bash 명령에서 허용 목록에 없는 환경변수에 그냥 값을 대입하던 경우가 권한 프롬프트를 우회하던 버그가 수정됐어요(보안 픽스). MCP 관련 수정도 포함돼 있지만 본문이 잘려 있어 정확한 내용은 원문 릴리스 노트를 확인하는 게 좋습니다.
