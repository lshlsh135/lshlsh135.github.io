이번 v2.1.146은 슬래시 커맨드 리네이밍 한 건과 Windows·MCP·백그라운드 세션 쪽 자잘한 버그 수정이 잔뜩 묶인 패치 릴리스예요. 가장 눈에 띄는 변화는 /simplify가 /code-review로 이름이 바뀌었고, 뒤에 옵션으로 노력 수준(예: /code-review high)을 붙일 수 있다는 점이에요. 또 Auto 모드가 그동안 AskUserQuestion을 막아버리던 동작이 완화돼서, 사용자나 스킬이 명시적으로 그 도구에 의존할 때는 질문이 정상적으로 뜨도록 바뀌었어요. Windows 사용자에게 의미 있는 수정도 많은데, winget이나 Microsoft Store로 pwsh를 깐 환경에서 PowerShell 도구가 "command line is invalid"로 깨지던 v2.1.124 회귀가 고쳐졌고, Windows Terminal에서 백그라운드 세션이 스트리밍 중 풀스크린 깜빡임을 일으키던 문제, 백그라운드 작업 워크트리를 지울 때 NTFS 정션을 따라가 메인 저장소까지 건드리던 문제도 잡혔어요. MCP 쪽은 페이지네이션 서버에서 resources/list·resources/templates/list·prompts/list가 2페이지부터 항목을 누락하던 버그가 수정됐고, 백그라운드 세션이 "don't ask again"으로 이미 허용한 권한을 다시 묻거나, 입력이 스킬·커스텀 슬래시 커맨드뿐일 때 /background가 세션 생성을 거부하던 문제, 업데이트 실패 시 자동 업데이터 상태 표시줄이 현재 버전을 안 보여주던 문제까지 함께 정리됐어요.
