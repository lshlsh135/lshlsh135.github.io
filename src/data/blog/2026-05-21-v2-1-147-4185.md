v2.1.147에서는 결정론적 멀티 에이전트 오케스트레이션을 위한 Workflow 도구가 추가됐는데 기본은 꺼져 있고 CLAUDE_CODE_WORKFLOWS=1 환경변수로 켜야 합니다. claude agents에서 Ctrl+T로 핀 고정한 백그라운드 세션은 이제 유휴 상태에서도 살아 있고, Claude Code 업데이트 적용 시 제자리에서 재시작되며, 메모리 압박이 와도 핀 안 된 세션부터 먼저 정리됩니다. /simplify는 /code-review로 이름이 바뀌었고 /code-review high 처럼 노력 수준을 지정해 correctness 버그를 보고하며, --comment 플래그를 붙이면 GitHub PR 인라인 코멘트로 결과를 남길 수 있습니다(기존 cleanup-and-fix 동작은 제거). 보안 면에서는 REPL과 Workflow 도구 샌드박스를 prototype-pollution 및 thenable 기반 이스케이프에 대해 강화했고, 자동 업데이터는 일시적 네트워크 실패를 재시도하며 실패 시 에러 카테고리와 OS 에러 코드, 현재 버전을 보여줍니다. 그 외 대용량 파일 편집의 diff 렌더링 성능이 개선됐고, 프롬프트 히스토리는 연속된 중복 항목을 더 이상 기록하지 않습니다.
