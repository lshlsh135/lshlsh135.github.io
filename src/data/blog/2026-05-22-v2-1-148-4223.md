Claude Code v2.1.148 패치 릴리스로, 일부 사용자에게서 Bash 도구가 모든 명령에 대해 exit code 127을 반환하던 회귀 버그가 수정되었어요. 이 회귀는 바로 직전 버전인 2.1.147에서 도입된 것이라, 해당 버전을 쓰던 분들은 이번 패치로 곧장 올리는 게 좋습니다. exit code 127은 보통 '명령을 찾을 수 없음'을 의미하기 때문에, 영향을 받은 환경에서는 사실상 Bash 도구가 전혀 동작하지 않는 상태였을 거예요. 다른 변경 사항은 공지에 포함돼 있지 않고, 이번 릴리스는 이 버그픽스 하나에 집중된 핫픽스 성격으로 보입니다.
