이번 v2.1.149 릴리스는 /usage·/diff UX 개선과 PowerShell 권한 우회·sandbox 허용 범위 관련 보안 버그 수정이 핵심이에요. /usage가 한도 사용량을 스킬, 서브에이전트, 플러그인, MCP 서버별로 카테고리화해서 보여줘서 무엇이 토큰을 먹고 있는지 한눈에 파악할 수 있고, /diff 상세 화면은 이제 화살표·j/k·PgUp/PgDn·Space·Home/End 키로 스크롤할 수 있어요. 마크다운 출력은 GFM 체크박스(- [ ] / - [x])를 실제 체크박스로 렌더링하고, 엔터프라이즈는 allowAllClaudeAiMcps 관리 설정으로 claude.ai 클라우드 MCP 커넥터를 managed-mcp.json과 함께 로드할 수 있게 됐어요. 보안 수정으로는 PowerShell 내장 cd 함수(cd.., cd\, cd~, X:)가 작업 디렉토리를 감지 없이 바꿔 워크스페이스 밖 파일을 읽게 했던 권한 우회, git worktree에서 sandbox 쓰기 허용 범위가 공유 .git 디렉토리 대신 메인 리포 루트 전체로 잡히던 버그, dotnet.exe build * 같은 PowerShell prefix/wildcard 허용 규칙이 네이티브 실행파일·스크립트를 사전 승인하지 못하던 문제가 포함돼요.
