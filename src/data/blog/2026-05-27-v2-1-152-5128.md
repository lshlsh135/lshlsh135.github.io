이번 릴리즈는 /code-review --fix가 리뷰 후 결과를 작업 트리에 직접 적용하고 재사용·단순화·효율성 제안을 표면화하도록 바뀌었고, /simplify는 이제 /code-review --fix를 내부적으로 호출합니다. Skills와 슬래시 커맨드는 frontmatter에 disallowed-tools를 지정해 해당 스킬이 활성인 동안 특정 도구를 모델에서 차단할 수 있게 됐고, /reload-skills 커맨드로 세션을 재시작하지 않고도 스킬 디렉터리를 다시 스캔할 수 있습니다. SessionStart 훅은 reloadSkills: true를 반환해 같은 세션 안에서 새 스킬을 즉시 사용 가능하게 만들거나, hookSpecificOutput.sessionTitle로 시작·재개 시점에 세션 제목을 설정할 수 있고, 새로 추가된 MessageDisplay 훅 이벤트는 어시스턴트 메시지가 화면에 표시되는 단계에서 텍스트를 변형하거나 숨길 수 있게 해줍니다. 관리자용으로는 pluginSuggestionMarketplaces 설정이 추가돼 컨텍스트 기반 팁으로 제안되는 플러그인을 조직 마켓플레이스로 화이트리스트할 수 있고, claude plugin marketplace remove는 --scope user|project|local 인자를 받습니다.
