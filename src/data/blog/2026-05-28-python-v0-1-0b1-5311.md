Anthropic 관련 Python SDK의 0.1.0b1 베타 버전이 릴리스됐다는 공지다. 버전 표기에서 보이듯 0.1.x 라인의 첫 베타(b1) 단계이며, 정식 안정판 이전의 프리릴리스에 해당한다. 본문이 제공되지 않아 변경 내역, 신규 기능, 호환성 영향 같은 구체적인 정보는 이 공지만으로는 확인할 수 없다. 실제 적용을 검토 중이라면 릴리스 노트나 CHANGELOG, PyPI 페이지에서 변경사항을 직접 확인하는 게 안전하다.
