Anthropic SDK 0.105.0이 2026-05-28에 릴리스됐어요. 새 기능으로 claude-opus-4-8 모델 지원, 대화 중간 system 블록(mid-conversation system blocks), usage.output_tokens_details 필드 지원이 추가됐고(f18b014), 커스텀 파일 사이즈 캡 설정도 가능해졌어요(#1825, 7e5f944). 잡일 항목으로 examples의 managed-agents private-sandbox-worker가 self-hosted-sandbox-worker로 이름이 바뀌었고(#1822), 문서에서 리터럴 개행 문자를 교체하는 정리도 들어갔어요. claude-opus-4-8 같은 신규 모델을 바로 호출하거나, 대화 중간에 system 지시를 끼워 넣는 패턴, 출력 토큰 상세 통계가 필요한 개발자라면 이 버전으로 올리는 게 좋아요.
