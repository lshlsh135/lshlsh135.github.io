Claude Code v2.1.153 업데이트가 나왔어요. github/git 플러그인 마켓플레이스 소스에 `skipLfs` 옵션이 추가되어 clone·update 시 Git LFS 다운로드를 건너뛸 수 있고, npm 글로벌 설치가 자동 업데이트되지 않을 때는 일회성 안내가 뜨면서 `/doctor`가 해결책을 알려줘요. 상태줄(status line) 명령에는 `COLUMNS`·`LINES` 환경 변수가 전달돼 터미널 폭에 맞춘 출력 크기 조절이 가능해졌고, claude agents 디스패치 입력 자동완성이 프로젝트 스킬뿐 아니라 네이티브 슬래시 커맨드와 번들 스킬까지 제안하며 PR 컬럼은 단일은 `PR #N`, 여러 개는 `N PRs`로 표시돼요. claude doctor가 마지막 업데이트 시도 결과를 보여주고, MCP 서버·커넥터의 인증 필요 알림이 한 개로 통합됐으며 macOS에서는 백그라운드 에이전트가 "Claude Code"로 표시되고 업그레이드 후에도 권한이 유지돼요. v2.1.147에서 생긴 stateful MCP 서버(선택적 GET SSE 스트림 없음)의 tools/list 재연결 루프 회귀 버그도 수정됐어요.
