Claude Code v2.1.157은 플러그인 사용성을 개선해 `.claude/skills` 디렉터리의 플러그인을 마켓플레이스 없이 자동 로드하고, `claude plugin init <name>`으로 새 플러그인 골격을 만들며, `/plugin` 인자(서브커맨드·설치된 플러그인명·알려진 마켓플레이스)에 자동완성을 추가했습니다. 에이전트 쪽에서는 settings.json의 agent 필드가 디스패치된 세션에도 적용되고 `--agent <name>`으로 덮어쓸 수 있으며, EnterWorktree로 세션 중간에 Claude가 관리하는 워크트리를 전환할 수 있고, 작업이 끝난 워크트리는 잠금 해제 상태로 남아 `git worktree remove/prune`로 정리됩니다. 텔레메트리는 `OTEL_LOG_TOOL_DETAILS=1`일 때 tool_decision 이벤트에 tool_parameters(bash 명령, MCP/스킬 이름)가 포함됩니다. 버그 수정으로는 붙여넣기·MCP·다이얼로그로 첨부된 처리 불가 이미지(0바이트·손상)가 요청을 크래시시키지 않고 텍스트 플레이스홀더로 처리되며, auto 및 bypass-permissions 모드에서 데스크톱 사용 시 뜨던 샌드박스 네트워크 권한 프롬프트 문제도 고쳐졌습니다.
