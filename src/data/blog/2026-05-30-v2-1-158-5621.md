Claude Code v2.1.158에서 Auto 모드가 Bedrock, Vertex, Foundry에서도 사용할 수 있게 됐어요. 대상 모델은 Opus 4.7과 Opus 4.8이에요. 사용하려면 환경변수 CLAUDE_CODE_ENABLE_AUTO_MODE=1을 설정해서 직접 켜야 합니다(기본값은 꺼짐). 세 곳의 클라우드 모델 제공 경로(Bedrock·Vertex·Foundry)를 쓰면서 Opus 4.7/4.8을 돌리는 사용자에게 해당되는 변경입니다.
