이번 릴리스는 보안 관련 프롬프트 추가와 여러 버그 수정에 집중했어요. 쉘 시작 파일(.zshenv, .zlogin, .bash_login)과 ~/.config/git/에 쓰기 전, 그리고 acceptEdits 모드에서 코드 실행 권한을 주는 빌드 도구 설정 파일(.npmrc, .yarnrc*, bunfig.toml, .bazelrc, .pre-commit-config.yaml, .devcontainer/ 등)에 쓰기 전 확인 프롬프트가 뜨도록 바뀌어, 의도치 않은 명령 실행을 막아줍니다. 또한 단일 파일 grep/egrep/fgrep로 파일을 본 경우 Edit 전에 따로 Read를 요구하지 않도록 완화됐고, WSL에서 copy-on-select가 OSC 52 대신 PowerShell interop를 사용해 MobaXterm 같은 터미널에서도 Windows 클립보드에 제대로 복사됩니다. 버그 수정으로는 완료된 세션이나 밤새 retire 후 재연결된 백그라운드 세션을 복원할 때 대화 기록이 사라지고 원래 프롬프트가 재실행되던 문제, claude --bg가 백그라운드 데몬이 cold일 때 간헐적으로 "socket missing"으로 실패하던 문제가 해결됐어요.
