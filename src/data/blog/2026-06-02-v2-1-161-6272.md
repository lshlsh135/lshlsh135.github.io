Claude Code v2.1.161 변경사항이에요. OTEL_RESOURCE_ATTRIBUTES 값이 메트릭 데이터포인트의 라벨로 포함돼서, team이나 repo 같은 커스텀 차원으로 사용량 메트릭을 쪼개 볼 수 있게 됐어요. 작업이 병렬로 펼쳐질 때 agents 행에 상세 정보 앞에 done/total이 표시되고 peek은 가장 오래 걸리는 항목을 보여주며, /mcp는 한 번도 로그인한 적 없는 claude.ai 커넥터를 'Show unused connectors' 행 뒤로 접어둬요. 병렬 도구 호출에서는 Bash 명령 하나가 실패해도 같은 배치의 다른 호출이 취소되지 않고 각각 독립적으로 결과를 반환하도록 바뀌었고, 풀스크린 모드의 클립보드는 리눅스에서 wl-copy/xclip/xsel를 쓸 수 있으면 그걸 사용해 클립보드와 PRIMARY 선택 영역 양쪽에 복사해요. 버그 수정으로는 /effort 다이얼로그·워크플로우 애니메이션·프롬프트 키워드 시머가 'Reduce motion' 설정을 따르지 않던 문제, 그리고 forceLoginOrgUUID/forceLoginMethod 관리 정책이 Bedrock 등 서드파티 프로바이더 세션을 막던 문제가 고쳐졌어요.
