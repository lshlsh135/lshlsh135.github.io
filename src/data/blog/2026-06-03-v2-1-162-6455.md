Claude Code v2.1.162 변경 사항을 정리한 릴리스다. `claude agents --json` 출력에 waitingFor 필드가 추가돼 대기 중인 세션이 무엇에 막혀 있는지(예: 권한 프롬프트) 보여주고, `--tools`에서 Grep/Glob을 명시적으로 나열하면 검색 기능이 내장된 네이티브 빌드에서 전용 검색 도구가 실제로 제공된다(이전엔 이 이름들이 조용히 무시됐다). `/effort`는 선택한 레벨이 새 세션의 기본값으로 유지될지 확인해 주고, 자동완성 메뉴에서 슬래시 커맨드를 클릭하면 즉시 실행되지 않고 프롬프트에 채워 넣은 뒤 Enter로 실행하도록 바뀌었으며, Remote Control은 시작 메시지 대신 세션 링크가 달린 하단 고정 풋터 알약으로 표시된다. 또 에디터 리브랜드에 맞춰 /ide·/terminal-setup·/scroll-speed에서 Windsurf가 Devin Desktop으로 이름이 바뀌었다. 버그 수정으로는 설정 디렉터리가 읽기 전용이거나 쓰기 불가일 때 빈 화면 없이 인메모리 설정으로 시작하며 시작 오류를 표시하도록 고친 점, WebFetch 권한 규칙이 일부 내장 기능에 적용되지 않던 문제 수정이 포함된다.
