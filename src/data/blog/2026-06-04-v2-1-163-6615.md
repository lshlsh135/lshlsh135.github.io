Claude Code v2.1.163은 관리형 설정과 훅·MCP 동작을 손본 패치 릴리스예요. 새로 추가된 requiredMinimumVersion·requiredMaximumVersion 관리형 설정은 버전이 허용 범위를 벗어나면 Claude Code 실행을 막고 승인된 버전으로 안내하며, 설치된 플러그인을 보는 /plugin list 명령(--enabled/--disabled 필터 지원)과 /btw 답변의 원본 마크다운을 서식 그대로 복사하는 'c to copy' 단축키도 들어왔어요. 훅 쪽에서는 Stop·SubagentStop 훅이 hookSpecificOutput.additionalContext를 반환해 훅 오류로 처리되지 않고 턴을 이어갈 수 있게 됐고, 스킬 명령 본문에서 숫자 앞 리터럴 $를 넣는 \$ 이스케이프 문법이 추가됐으며, stdio MCP 서버도 --resume 시 훅·Bash와 동일한 CLAUDE_CODE_SESSION_ID를 받게 됐어요. 버그 수정으로는 백그라운드 명령이 끝나지 않을 때 claude -p가 최종 결과 뒤로 무한 대기하던 문제(이제 stdin이 닫히면 결과 후 약 5초 뒤 백그라운드 셸 종료)와 ANTHROPIC_API_KEY 관련 claude -p 실패가 다뤄졌어요(발췌가 중간에 잘려 정확한 수정 내용은 일부 미상).
