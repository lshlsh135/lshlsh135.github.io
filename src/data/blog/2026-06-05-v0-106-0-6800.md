2026년 6월 5일자로 나온 SDK 0.106.0 릴리스로, 가장 눈에 띄는 변화는 API에서 Claude Opus 4.1을 deprecated(지원 중단 예정)으로 표시한 점입니다. 버그 수정으로는 Foundry 클라이언트의 copy()와 with_options()가 정상 동작하도록 고쳤고, 스키마 변환 시 루트가 $ref일 때 $defs를 보존하도록 수정했습니다(#1642). 이 외에 아티팩트 URL·브랜치명·비공개 레포명 정리 같은 내부 정비 작업이 포함됐고, 문서에서는 보안 취약점 신고 경로를 Anthropic의 HackerOne 프로그램으로 안내하도록 바꿨습니다. Opus 4.1을 쓰고 있다면 deprecated 표시를 확인하고 후속 모델로의 이전을 검토해 두는 게 좋습니다.
