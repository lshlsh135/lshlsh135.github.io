Claude Code v2.1.166 변경사항을 정리한 릴리스 노트예요. 기본 모델이 과부하거나 사용 불가일 때 순서대로 시도할 최대 3개의 대체 모델을 지정하는 fallbackModel 설정이 추가됐고, --fallback-model 옵션이 이제 대화형 세션에도 적용돼요. 권한 규칙 쪽에서는 deny 규칙의 도구 이름 위치에 glob 패턴을 쓸 수 있게 됐는데("*"는 모든 도구 차단), allow 규칙은 MCP가 아닌 glob을 거부하고 deny 규칙에 모르는 도구 이름이 있으면 시작 시 경고를 띄워요. 보안 측면에서는 다른 Claude 세션이 SendMessage로 전달한 메시지가 더 이상 사용자 권한을 갖지 않도록 강화되어, 수신 측은 중계된 권한 요청을 거부하고 auto 모드는 이를 차단해요. 그 외에 MAX_THINKING_TOKENS=0·--thinking 비활성화·모델별 thinking 토글로 Claude API에서 기본 thinking을 끌 수 있게 됐고(3P 제공자는 그대로), API가 예기치 않은 재시도 불가 오류를 낼 때 대체 모델로 한 번 재시도하며(인증·레이트리밋·요청 크기·전송 오류는 즉시 노출), claude update는 업데이트 전에 대상 버전을 먼저 알려줘요.
