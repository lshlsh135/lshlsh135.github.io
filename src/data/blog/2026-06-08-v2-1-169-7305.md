이번 릴리스는 문제 해결과 안정성에 초점을 맞췄어요. 모든 커스터마이징(CLAUDE.md, 플러그인, 스킬, 훅, MCP 서버)을 끈 채로 실행하는 --safe-mode 플래그(환경변수 CLAUDE_CODE_SAFE_MODE)와, 세션 중 프롬프트 캐시를 깨지 않고 작업 디렉터리를 옮기는 /cd 커맨드가 추가됐어요. 또 번들 스킬·워크플로우·내장 슬래시 커맨드를 모델에게서 숨기는 disableBundledSkills 설정(환경변수 CLAUDE_CODE_DISABLE_BUNDLED_SKILLS)도 생겼습니다. 수정 사항으로는 긴 입력에서 위/아래 화살표가 줄바꿈된 시각적 행을 건너뛰고 명령 기록으로 점프하던 동작을 행 단위 이동으로 바로잡았고, 재연결·IDE 설정·--mcp-config 서버·원격 설정 로드 전 상황에서 엔터프라이즈 MCP 정책(allowedMcpServers/deniedMcpServers)이 적용되지 않던 문제와 원격 설정이 없는 조직의 느린 콜드 스타트를 고쳤어요. 그 밖에 macOS에서 매 턴 시작 시 발생하던 약 30~50ms UI 멈춤도 개선됐습니다.
