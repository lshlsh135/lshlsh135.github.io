2026년 6월 9일 릴리스된 0.108.0 버전은 주로 모델 지원과 폴백(fallback) 기능 추가에 초점이 맞춰져 있어요. api 쪽에서 claude-mythos-5와 claude-fable-5 모델 지원이 새로 들어갔고, 모델이 응답을 거부(refusal)할 때 서버 측에서 자동으로 다른 모델로 넘어가는 server-side fallback도 함께 지원돼요(커밋 6b76649). 또 client 쪽에는 server-side fallback을 지원하지 않는 API 제공자를 위해 클라이언트 측에서 폴백을 처리하는 미들웨어가 추가됐어요(같은 커밋 6b76649). 정리하면 거부 상황에서도 끊기지 않고 대체 모델로 이어가도록 양쪽(서버·클라이언트) 경로를 모두 보강한 업데이트입니다. 전체 변경 내역은 v0.107.1...v0.108.0 비교 로그에서 확인할 수 있어요.
