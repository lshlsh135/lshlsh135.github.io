이번 릴리스 노트는 두 가지를 다룬다. 첫째, 'Claude Fable 5'라는 새 모델(Mythos급으로 일반 사용에 맞게 안전화했고 기존에 일반 공개한 어떤 모델보다 성능이 앞선다고 소개)을 알리며, 사용하려면 버전 2.1.170으로 업데이트하라고 안내한다(공지 링크 첨부). 둘째, VS Code 통합 터미널이나 Claude Code 환경 변수를 물려받은 셸에서 실행했을 때 세션 트랜스크립트가 저장되지 않고 --resume 목록에도 나타나지 않던 버그를 고쳤다. 모델 소개 문구는 출처의 마케팅성 주장이라 실제 성능은 직접 확인이 필요하고, 실질적으로 체감되는 변화는 트랜스크립트 저장 버그 수정 쪽이다.
