Claude Code v2.1.172 릴리스 노트예요. 서브에이전트가 이제 자신의 서브에이전트를 최대 5단계 깊이까지 직접 생성할 수 있게 됐고, Amazon Bedrock은 AWS_REGION이 없을 때 ~/.aws 설정 파일에서 리전을 읽어 AWS SDK 우선순위와 동일하게 동작하며 /status에서 리전 출처를 확인할 수 있어요. 그 밖에 /plugin에서 마켓플레이스 플러그인을 둘러볼 때 검색 바가 추가됐고, claude_code.lines_of_code.count OTEL 메트릭에 model 속성이 붙었습니다. 버그 수정으로는 사용량 크레딧 없이 1M 컨텍스트를 쓰던 세션이 영구히 멈추던 문제(이제 표준 컨텍스트 한도 아래로 자동 컴팩트), 이미지가 여러 장일 때 '이미지를 처리할 수 없어 제거됨' 오류가 반복되던 문제, 워커 응답 후에도 에이전트 뷰가 최대 30초간 Working 스피너로 남던 문제, 사전 워밍된 워커에 배정된 백그라운드 에이전트가 다른 디렉터리의 프로젝트 설정(.mcp.json 승인, trust)을 읽던 문제 등이 해결됐어요. 백그라운드 세션 attach 실패 수정도 포함된 것으로 보이는데, 해당 항목은 원문이 중간에 잘려 있어 세부 내용은 확인이 필요합니다.
