Claude Code v2.1.174 릴리스예요. 전체화면 모드에서 마우스 휠 스크롤 가속을 끌 수 있는 wheelScrollAccelerationEnabled 설정이 새로 추가됐어요. /model 픽커 관련 수정이 여럿 들어갔는데, Default가 가리키는 모델 패밀리가 목록에서 숨겨지던 문제(이제 Max/Team Premium/Enterprise 플랜에서는 Opus, Pro/Team 플랜에서는 Sonnet이 별도 행으로 표시), 그리고 ANTHROPIC_DEFAULT_SONNET_MODEL로 다른 Sonnet을 지정해도 하드코딩된 버전 라벨이 표시되던 문제가 고쳐졌어요. 사용량 기반 과금을 쓰는 엔터프라이즈 계정에 'Fable 5 is now consuming usage credits' 배너가 잘못 뜨던 것과, Bedrock GovCloud 리전(us-gov-*)에서 추론 프로필 접두사를 us-gov 대신 global로 잘못 유도해 400 에러가 나던 것도 수정됐어요. 그 외에 백그라운드 세션이 데몬을 시작한 셸에서 다른 세션의 ANTHROPIC_* 프로바이더 환경 변수(게이트웨이 URL, 커스텀 헤더, /model 별칭)를 물려받던 버그도 잡혔어요.
