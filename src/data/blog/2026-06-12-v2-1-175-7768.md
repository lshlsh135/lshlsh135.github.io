Claude Code v2.1.175 릴리스에서 enforceAvailableModels 관리형(managed) 설정이 추가됐어요. 이 설정을 켜면 availableModels 허용 목록이 Default 모델에도 적용돼서, Default가 허용되지 않은 모델로 해석될 경우 허용 목록의 첫 번째 모델로 자동 폴백됩니다. 또 사용자 설정이나 프로젝트 설정으로 관리형 availableModels 목록을 임의로 넓히는 것도 더 이상 불가능해졌어요. 조직 차원에서 팀원들이 쓸 수 있는 모델을 강제로 통제해야 하는 관리자라면 눈여겨볼 만한 변경입니다.
