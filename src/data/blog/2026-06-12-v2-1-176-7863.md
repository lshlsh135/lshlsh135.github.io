Claude Code v2.1.176 릴리스예요. 세션 제목이 이제 대화에 쓰는 언어로 생성되고(language 설정으로 특정 언어 고정 가능), footerLinksRegexes 설정이 추가되어 푸터 줄에 정규식 매칭 링크 배지를 사용자 또는 관리형 설정으로 구성할 수 있어요. Bedrock 자격 증명 캐싱도 개선되어 awsCredentialExport에서 온 자격 증명이 기존 고정 1시간 대신 Expiration 시점까지 캐시됩니다. 모델 제한 쪽 수정도 들어갔는데, availableModels 강제 적용이 보강되어 ANTHROPIC_DEFAULT_*_MODEL 환경변수로 별칭 모델 선택을 차단된 모델로 우회할 수 없게 됐고, /fast도 허용 목록 밖 모델로 전환되는 경우 토글을 거부하며, Opus 4.8이 활성화되지 않은 조직에서 Fable 5의 auto 모드가 실패하던 문제는 분류기가 사용 가능한 최선의 Opus 모델로 폴백하도록 수정됐어요. 그 외에 Edit(src/**), Read(~/.ssh/**), Read(.env) 같은 문서화된 훅 if 조건 경로 패턴이 이제 올바르게 매칭되고, .claude/settings.json 관련 Linux 샌드박스 시작 실패 수정도 포함됐습니다.
