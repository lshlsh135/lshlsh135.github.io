Anthropic SDK 0.113.0 릴리스(2026-06-29)로, 핵심은 API에 20260318 버전의 web fetch 및 support tools 지원이 추가된 점입니다. 버그 수정으로는 async count_tokens에서 output_format/output_config 병합 블록이 누락되던 문제(#162)가 고쳐졌습니다. 잡일성 변경으로 토큰 카운팅 시 사용자 프로필 ID를 받을 수 있게 됐고, 일부 설명과 예시 값 문서가 갱신됐습니다. 새 web fetch 도구나 count_tokens를 쓰는 사용자라면 업데이트할 만한 패치 릴리스입니다.
