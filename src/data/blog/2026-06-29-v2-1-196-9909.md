Claude Code v2.1.196 업데이트로, 관리자가 조직 콘솔에서 조직 기본 모델을 지정할 수 있고 사용자가 직접 모델을 고르지 않았을 때 /model에 "Org default"(또는 "Role default")로 표시된다. 세션 시작 시 읽기 쉬운 기본 이름이 붙어 식별·메시지 보내기가 편해졌고, 채팅의 파일 첨부를 Cmd/Ctrl-클릭하면 Finder/Explorer에서 해당 파일이 열린다. 보안 측면에서는 claude mcp list/get가 더 이상 커밋된 .claude/settings.json으로 레포가 자체 승인한 .mcp.json 서버를 실행하지 않으며, 신뢰되지 않은 워크스페이스는 ⏸ Pending approval로 표시된다. 버그 수정으로는 백그라운드 작업을 깨울 때 transcript 오판독으로 대화가 영구 삭제되고 원래 프롬프트가 재실행되던 문제(이제 파일을 삭제하지 않고 따로 보관), 병렬 요청 중 사용 한도에 걸렸을 때 rate-limit 경고가 깜빡이며 사라지고 텔레메트리가 과다 집계되던 문제, 백그라운드 세션 턴 이후 recap 줄이 중복되던 문제가 포함된다.
