Claude Code v2.1.198 릴리스로, Claude in Chrome이 정식 출시(GA)됐고 백그라운드 에이전트 관련 개선이 눈에 띕니다. claude agents의 백그라운드 세션은 이제 입력이 필요하거나 끝날 때 Notification 훅(agent_needs_input / agent_completed)을 발생시키고, 워크트리에서 코드 작업을 마치면 멈춰 묻는 대신 알아서 커밋·푸시하고 draft PR을 엽니다. 차트·대시보드 설계를 돕는 /dataviz 스킬(실행 가능한 컬러 팔레트 검증기 포함)이 추가됐고, Gateway에는 AWS 기반 Claude Platform(anthropicAws)이 업스트림 제공자로 붙으면서 model-not-found 응답 시 페일오버 체인이 다음으로 넘어가도록 바뀌었습니다. 내장 Explore 에이전트는 haiku 대신 메인 세션 모델(opus 상한)을 물려받고, 서브에이전트와 컨텍스트 압축도 세션의 확장 사고(extended thinking) 설정을 상속해 위임 작업 품질이 올라갑니다. 그 외 응답 도중 짧은 네트워크 끊김(ECONNRESET 같은 일시 오류)이 턴을 중단시키던 문제를 백오프 재시도로 고쳤습니다.
