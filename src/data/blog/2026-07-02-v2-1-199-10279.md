이번 릴리스는 스킬 호출과 에러 처리 관련 버그 수정이 중심이에요. `/skill-a /skill-b` 처럼 슬래시 스킬을 여러 개 이어서 부를 때 이제 맨 앞 스킬 하나만이 아니라 앞쪽 스킬을 최대 5개까지 모두 로드하고, TLS 검사 프록시·NODE_EXTRA_CA_CERTS 누락·만료된 인증서 같은 SSL 인증서 오류는 재시도로 시간을 낭비하지 않고 즉시 실패하면서 해결 힌트를 바로 보여줘요. 스트리밍 응답 도중 overloaded/서버 오류가 나도 부분 출력을 버리지 않고 '미완성 응답' 표시와 함께 보존하고, 서브에이전트가 rate limit이나 서버 오류로 잘렸을 때 조용히 실패하는 대신 부분 결과를 부모 에이전트에 넘기며, 사용량 한도 초과 같은 API 오류를 성공으로 잘못 보고하던 문제도 이제 부모에게 오류로 정확히 전달돼요. 백그라운드 에이전트 쪽에서는 리눅스 데몬이 비정상 종료로 손상된 워커 레코드가 남았을 때 약 50초마다 자기 자신과 실행 중인 에이전트를 전부 죽이던 문제와, macOS에서 SSH로 콜드 스타트가 실패하던 문제가 고쳐졌어요.
