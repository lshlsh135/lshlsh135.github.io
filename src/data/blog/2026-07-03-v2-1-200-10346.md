Claude Code v2.1.200은 동작 기본값 변경 두 가지와 백그라운드 세션 관련 버그 수정에 집중한 릴리스입니다. AskUserQuestion 대화창이 이제 기본적으로 자동 진행되지 않으며, 유휴 타임아웃을 원하면 /config에서 별도로 켜야 합니다. 기본 권한 모드도 CLI·--help·VS Code·JetBrains 전반에서 "Manual"로 바뀌었고, --permission-mode manual과 "defaultMode": "manual" 표기가 기존 default와 함께 허용됩니다. 버그 수정으로는 .claude.json의 disabledMcpServers/enabledMcpServers가 배열이 아닐 때 시작 시 크래시, 절전/재개 후 백그라운드 세션이 조용히 멈추던 문제, Esc로 취소한 턴이 재실행되던 문제, 재사용된 PID가 박힌 오래된 daemon.lock 때문에 백그라운드 에이전트가 다시 시작되지 않던 문제가 포함됩니다. 또한 데몬 핸드오버가 임베디드 빌드 타임스탬프로 빌드 최신성을 판단하도록 바뀌어, 재설치된 구형 빌드가 데몬을 가로챌 수 없게 됐습니다.
