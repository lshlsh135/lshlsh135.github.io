이번 릴리스는 주로 백그라운드 세션 안정성과 인증 관련 개선에 초점을 맞췄어요. 로그인 만료가 임박하면 백그라운드 세션이 끊기기 전에 다시 인증할 수 있도록 경고를 띄워주고, 수동 권한 모드일 때는 푸터에 회색 ⏸ 배지를 표시해 현재 모드를 항상 볼 수 있게 했습니다. 세션의 추가 작업 디렉터리를 MCP roots/list에 반영하고 변경 시 notifications/roots/list_changed 알림도 보내요. 버그 수정으로는 macOS에서 백그라운드 에이전트 세션을 열거나 전환할 때 잘못된 저메모리 감지로 15~20초 멈추던 문제(2.1.196 회귀), 데몬 세션 토큰이 만료되면 세션이 영구적으로 응답 불능이 되던 문제(이제 자동 복구), claude agents로 돌아오면 실행 중이던 서브에이전트가 조용히 멈추고 프롬프트를 처음부터 다시 실행하던 문제(이제 작업이 이어짐), 그리고 매 턴마다 전체 트랜스크립트를 재분석하던 컨텍스트 사용량 표시기의 메모리·CPU 회귀 등이 포함됩니다.
