Claude Code v2.1.205 업데이트로, 새 기능 하나와 다수의 버그 수정이 담겼습니다. 신규로는 auto 모드에서 세션 트랜스크립트(session transcript) 파일 변조를 차단하는 규칙이 추가됐습니다. 버그 수정으로는 (1) `--json-schema`가 잘못된 스키마일 때 조용히 비구조화 출력을 내던 문제와 `format` 키워드를 쓰는 스키마가 거부되던 문제, (2) `--max-turns` 한도로 턴이 끝날 때 Claude 작업 중 보낸 메시지가 조용히 사라지던 문제, (3) Windows 워크트리 제거 시 내부에 NTFS 정션이나 디렉터리 심링크가 있으면 워크트리 밖 파일까지 삭제되던 문제를 고쳤습니다. 그 외에 SendMessage로 재개한 백그라운드 에이전트가 목록에서 계속 'failed'/'completed'로 표시되던 점, 읽을 텍스트가 없는 턴에서 백그라운드 작업이 'needs input'에서 'working'으로 되돌아가던 점, 업그레이드 재시작 중인 백그라운드 에이전트에 `claude attach`가 오류를 내던 점, 30K 인라인 한도를 넘긴 Bash 출력에서 생성된 PR이 세션-PR 링크에서 누락되던 점, `claude mcp add-from-claude-desktop`이 멈추던 점 등이 함께 수정됐습니다.
