Claude Code v2.1.206 업데이트로, `/cd`에 `/add-dir`와 동일한 디렉터리 경로 자동완성이 추가되고, `/doctor`는 코드베이스에서 유추 가능한 내용을 잘라 체크인된 CLAUDE.md를 줄이도록 제안하는 검사가 생겼어요. `/commit-push-pr`은 이제 origin뿐 아니라 저장소에 설정된 push 리모트(remote.pushDefault, 또는 리모트가 하나뿐일 때 그 리모트)로의 git push도 자동 허용하고, `/login`은 Anthropic이 운영하는 공개 게이트웨이 엔드포인트를 지원합니다. EnterWorktree는 프로젝트의 .claude/worktrees/ 밖에 있는 워크트리로 진입할 때 확인을 묻고, 백그라운드 에이전트는 업데이트 직후 백그라운드에서 새 버전으로 올려 나중에 붙을 때 느린 stale-session 업그레이드를 피하도록 바뀌었어요. 버그 수정으로는 만료된 로그인이 'There's an issue with the selected model'이라는 오해 소지 있는 에러를 내던 문제(이제 /login을 안내), `claude --resume`·`--continue` 시작 시 키 입력이 먹히지 않던 문제 등이 포함됩니다.
