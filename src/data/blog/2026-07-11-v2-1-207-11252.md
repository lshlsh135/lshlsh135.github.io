Claude Code v2.1.207 업데이트로, 이제 Bedrock·Vertex AI·Foundry에서 CLAUDE_CODE_ENABLE_AUTO_MODE 옵트인 없이 Auto 모드를 쓸 수 있고 원치 않으면 settings의 disableAutoMode로 끌 수 있어요. 버그 수정으로는 아주 긴 목록·표·문단·코드 블록을 스트리밍할 때 터미널이 멈추고 키 입력이 밀리던 문제, 비대화형 실행(claude -p, SDK)에서 원격 관리 설정이 보안 동의 대화상자 없이 영구 동의로 기록되던 문제, 정상적인 시스템 대화 업데이트에 잘못 뜨던 prompt-injection 경고가 해결됐어요. 또 자동 업데이터가 릴리스마다 ~/.local/bin/claude의 커스텀 런처 스크립트나 심링크를 덮어쓰던 문제도 고쳐졌고, 이제 /doctor가 외부에서 관리되는 런처를 알려줍니다. 그 밖에 출력 리다이렉트가 /dev/null뿐인 cd 복합 명령이 권한을 묻던 문제, 응답 스트리밍이 끝날 때 트랜스크립트가 답변 시작 위로 튀던 문제, extensions.worktreeConfig가 저장소 .git/config에 남던 문제도 정리됐어요.
