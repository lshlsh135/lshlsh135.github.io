Claude Code v2.1.208 업데이트로, 스크린 리더 사용자를 위한 평문 렌더링 모드(screen reader mode)가 추가됐어요. `claude --ax-screen-reader` 실행, `CLAUDE_AX_SCREEN_READER=1` 환경변수, 또는 settings에 `"axScreenReader": true`를 넣어 켤 수 있고, vim 모드에서 `jj` 같은 두 글자 시퀀스를 Escape로 매핑하는 `vimInsertModeRemaps` 설정과 사내 런처를 강제하는 `CLAUDE_CODE_PROCESS_WRAPPER`(모든 Claude Code self-spawn을 지정 래퍼 실행파일로 통과)도 들어왔어요. 전체화면 모드의 다중 선택 메뉴·'Other' 입력행에서 마우스 클릭도 지원합니다. 버그 수정으로는, fast mode를 지원하는 모델로 되돌렸을 때 꺼진 채 남던 문제가 이제 설정에 켜져 있으면 자동 복원되고, 백그라운드 에이전트에 입력한 답변이 전송 실패 시 사라지던 문제도 텍스트를 저장해 세션 재시작 때 전달하도록 고쳤어요. 또한 업데이트로 바이너리가 교체된 뒤 백그라운드 세션 attach가 'Couldn't start the background daemon' 오류로 영구 실패하던 문제도 수정됐습니다.
