이번 v2.1.210은 주로 버그 수정과 UI 개선 위주의 업데이트예요. 접힌 도구 요약 줄에 실시간 경과 시간 카운터가 추가돼서, 오래 걸리는 도구 호출이 멈춘 것처럼 보이지 않고 시간이 째깍째깍 흘러가는 게 보이고요. 또 Write(path)·NotebookEdit(path)·Glob(path) 권한 규칙에는 시작 시 경고가 뜨는데, 대신 Edit(path)나 Read(path)를 쓰라고 안내해줍니다. 버그 수정으로는 isolation: 'worktree' 서브에이전트가 자기 격리된 워크트리가 아니라 메인 저장소 체크아웃에 git 변경 명령을 실행하던 문제, ultracode 키워드 opt-in이 웹훅 페이로드나 전달된 PR 코멘트 같은 사람이 아닌 입력에서도 발동하던 문제, 붙여넣기 마커가 외부 에디터에 È/É 같은 이상한 문자로 새어 나가던 문제가 고쳐졌어요. 그리고 claude attach가 세션 전환 중 'job not found'나 'agent is still starting' 오류로 실패하던 것도 데몬이 안정될 때까지 기다리도록 바뀌면서 개선됐습니다.
