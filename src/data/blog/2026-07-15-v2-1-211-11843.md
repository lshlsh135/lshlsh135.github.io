Claude Code v2.1.211 릴리스는 새 기능 하나와 다수의 버그 수정을 담았습니다. 서브에이전트의 텍스트와 thinking을 stream-json 출력에 포함시키는 `--forward-subagent-text` 플래그와 `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 환경변수가 추가됐습니다. 보안 쪽에서는 채팅 채널로 전달되는 권한 미리보기가 양방향 오버라이드·제로폭·유사 따옴표 문자를 무력화하지 않아 도구 입력이 승인 메시지를 시각적으로 조작할 수 있던 문제를 고쳤고, unsandboxed Bash에서 auto 모드가 PreToolUse 훅의 ask 결정을 덮어쓰던 동작도 이제 훅의 ask가 최소한 프롬프트를 띄우도록 바로잡았습니다. 여러 세션이 하나의 자격증명 저장소를 공유할 때 절전 해제 후 동시에 로그아웃되던 문제, 웹 세션이 유휴 상태에서 깨어난 뒤 플러그인 MCP 서버가 재연결되지 않던 문제도 수정됐습니다. 그 밖에 Vertex·Bedrock에서 모델이 명시적으로 설정됐는데도 시작 시 기본 Opus를 시도하며 잘못된 폴백 알림을 띄우던 문제, 명시적 모델 오버라이드로 생성된 서브에이전트가 부모 모델로 되돌아가던 문제도 함께 해결됐습니다.
