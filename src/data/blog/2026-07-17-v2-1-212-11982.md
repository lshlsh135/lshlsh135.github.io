Claude Code v2.1.212에서 `/fork`가 대화를 새 백그라운드 세션(claude agents에 자체 행으로 표시)으로 복사하고 계속 작업할 수 있게 바뀌었고, 예전에 세션 안에서 서브에이전트를 띄우던 기능은 `/subtask`로 분리됐어요. 폭주하는 반복 루프를 막기 위해 세션당 WebSearch 호출 한도(기본 200, `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`으로 조절)와 서브에이전트 생성 한도(기본 200, `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`으로 조절, `/clear` 시 예산 리셋)가 추가됐습니다. 2분 넘게 도는 MCP 도구 호출은 세션을 계속 쓸 수 있도록 자동으로 백그라운드로 넘어가며, 기준값 조절이나 비활성화는 `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`로 합니다. 기본 auto-mode 설정을 되돌리는 `claude auto-mode reset`(확인 프롬프트가 뜨고 `--yes`로 건너뛰기 가능)이 생겼고, agent view에서 `/resume`를 치면 목록에서 삭제된 세션까지 포함한 과거 세션 선택기가 열려 고른 세션을 백그라운드로 재개해 줍니다. 그 외에 plan mode 관련 버그가 수정됐어요.
