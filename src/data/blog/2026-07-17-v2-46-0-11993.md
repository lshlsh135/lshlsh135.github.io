어떤 API SDK의 2.46.0 릴리스(2026-07-17)로, 주로 조직 프로젝트의 서비스 계정 관련 기능이 추가됐어요. 새 기능으로는 `/organization/projects/{project_id}/service_accounts/{service_account_id}/api_keys` 엔드포인트가 생겼고, `APIKeyListParams`에 `owner_project_access` 파라미터가 추가됐습니다. 버그 수정으로는 생성된 타입 호환성을 유지하도록 처리했고, 베타 표시(beta annotation) 호환용 별칭을 제거했어요. 전반적으로 프로젝트 단위의 API 키·서비스 계정을 다루는 개발자에게 관련된 마이너 업데이트로 보입니다.
