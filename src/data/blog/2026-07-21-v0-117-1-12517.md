2026년 7월 21일 릴리스된 v0.117.1 패치 버전 소식이에요. 핵심 버그 수정은 AWS 관련으로, AnthropicAWS.copy() 사용 시 자격 증명(credentials)이 올바르게 처리되지 않던 문제를 고쳤습니다. API 쪽에서는 새로운 refusal 카테고리 지원이 추가됐고, 의존성 정리로 http-snapshot을 0.1.9로 올리고 httpx_aiohttp는 메이저 버전을 고정(pin)했어요. 그 외에는 문서 소폭 업데이트와 코드젠 관련 내부 변경 정도라, AWS(Bedrock) 경로에서 클라이언트를 copy()로 복제해 쓰는 경우가 아니라면 급하게 올릴 필요는 없는 유지보수성 릴리스입니다.
