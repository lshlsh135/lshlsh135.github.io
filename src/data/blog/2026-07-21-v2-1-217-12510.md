Claude Code v2.1.217 릴리스 노트예요. 프롬프트 입력창에 이모지 숏코드 자동완성이 추가되어 :heart: 를 치면 ❤️가 들어가고 :hea 까지만 쳐도 제안이 뜨는데, 원치 않으면 emojiCompletionEnabled 설정으로 끌 수 있어요. 디스크 가득 참 등으로 트랜스크립트 저장이 실패하거나 상속된 환경 변수 때문에 세션 저장이 꺼진 경우, 조용히 기록을 잃는 대신 경고를 띄우도록 바뀌었어요. 버그 수정으로는 잘린 MCP 도구 출력이 원본 전체를 메모리에 계속 붙잡던 메모리 누수, Windows 자동 업데이트 실패 시 claude.exe가 사라지던 문제(이제 보존된 실행 파일을 자동 복원), 심볼릭 링크 작업 디렉터리를 정규화하지 않아 백그라운드 세션이 워크스페이스 폴더를 벗어날 수 있던 격리 문제가 잡혔어요. 그 밖에 Bedrock의 Claude Opus 4.8에서 auto-compact가 아예 동작하지 않고 한도 초과 후 /compact도 실패하던 문제, Claude Desktop 세션에서 기업용 mTLS·TLS 검증·OAuth 스코프·프록시 설정이 무시되던 문제, 스크린 리더 모드 관련 수정도 포함됐어요.
