claude CLI의 v2.1.218 업데이트로, /code-review가 백그라운드 서브에이전트로 실행되도록 바뀌어 리뷰 작업이 대화 내역을 차지하지 않고, 겹쳐 쌓인 슬래시 커맨드도 리뷰 대상으로 유지돼요. --ax-screen-reader 모드에서는 단어·줄 단위 삭제(Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) 시 삭제된 텍스트를 스크린리더가 읽어주는 기능이 추가됐고요. 버그 수정으로는 C:\Users\unicorn처럼 \u로 시작하는 구간이 있는 Windows 경로가 CJK 문자로 깨져 해당 파일에 접근할 수 없게 되던 문제와, 왼쪽 화살표 키가 실행 취소도 없이 대화를 날려버리던 문제(이제 편집 직후에는 확인을 묻고, 에이전트 뷰에서 Esc를 누르면 백그라운드로 보냈던 대화로 돌아감)가 해결됐어요. claude mcp list와 /mcp는 서버 연결에 실패하면 HTTP 상태와 에러 텍스트를 보여주고, MCP 설정값에 숨은 앞뒤 공백이 있으면 경고도 띄워줘요. 붙여넣은 줄바꿈을 Ctrl+J로 인코딩하는 터미널에서 여러 줄 붙여넣기가 줄바꿈 대신 j가 들어간 한 줄로 합쳐지던 문제도 고쳐졌어요.
