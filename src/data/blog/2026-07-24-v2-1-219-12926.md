Claude Code v2.1.219 릴리스 노트인데, 가장 큰 변화는 Claude Opus 5(claude-opus-5)가 기본 Opus 모델로 추가된 것으로, 1M 컨텍스트를 지원하고 fast 모드 가격은 Mtok당 $10/$50입니다. 설정 쪽에서는 샌드박스 명령이 허용 목록 밖 호스트에 접속하려 할 때 프롬프트 없이 바로 차단하는 sandbox.network.strictAllowlist와, 워크플로우 크기 가이드라인을 설정 파일에서 지정하는 workflowSizeGuideline 키가 새로 생겼고, /add-dir나 SDK의 register_repo_root로 세션 중간에 작업 디렉터리가 등록되면 발동하는 DirectoryAdded 훅도 추가됐어요. 헤드리스(stream-json) 쪽도 보강돼서 init 이벤트에 --mcp-config 항목 중 검증에서 걸러진 서버를 알려주는 mcp_server_errors 필드가 들어갔고(터미널 실행 시엔 시작 경고 출력), --forward-subagent-text를 켜면 depth-2 이상에서 생성된 중첩 서브에이전트의 텍스트도 스폰한 Agent tool_use id 기준으로 전달됩니다. 버그 수정으로는 claude -p 실행 중 API 에러가 나면 이미 생성된 답변까지 통째로 날아가던 문제가 고쳐졌어요. 원문이 중간에 잘려 있어서('Added HTT...') 이 뒤에 항목이 더 있을 수 있습니다.
