OpenAI Python SDK 2.53.0이 2026-08-03에 릴리스됐어요. 기능 추가로는 api 영역에서 gpt-5.5 모델과 Responses 타입에 tool name/namespace가 들어갔습니다(#3569, dd1202d). 버그 수정은 CI 쪽 하나로, NumPy 소스 빌드와 중복된 HTTPX 커버리지를 피하도록 정리했어요(#3573, b58332f). 새 모델 이름을 타입 수준에서 인식해야 하는 사용자라면 올려둘 만한 패치 릴리스입니다.
