Claude Code v2.1.221은 VSCode 확장에 Focus view를 추가했는데, 채팅 메뉴 토글로 도구 실행 내역을 턴별 요약 뒤에 접어두고 실행 중인 도구만 라이브로 표시해 주며 Ctrl+Alt+F 또는 "Claude Code: Toggle Focus view" 명령으로 켜고 끌 수 있습니다. 샌드박스 자격증명 파일에는 Linux와 WSL 한정으로 mode: "mask"가 생겼는데, 샌드박스 안의 명령은 파일 전체 또는 extract regex로 잡아낸 구간만 담긴 sentinel 사본을 읽고 실제 값은 샌드박스 프록시가 외부로 나가는 시점에 끼워 넣습니다(macOS에서는 파일 마스킹이 deny로 폴백됩니다). 보안 쪽에서는 zsh가 [[ ]] 정규식 조건문 안에 숨긴 명령을 Bash 도구 권한 검사를 우회해 실행할 수 있던 문제가 수정돼 이제 해당 명령도 권한을 묻고, 경로 처리와 관련된 PowerShell 권한 검사 문제도 함께 고쳐졌습니다. 그 외에 claude plugin validate는 마켓플레이스나 플러그인 이름이 Claude Desktop의 managed marketplace sync에서 거부될 만한 경우 경고를 띄우고, claude-api 스킬에는 구형 모델 기준으로 작성된 프롬프트·도구 설명 패턴을 점검해 주는 prompt-audit 서브커맨드가 추가됐습니다.
