v2.1.222는 새 기능 없이 버그 수정만 모은 패치예요. 가장 눈에 띄는 건 격리 관련 수정 두 건인데, worktree 격리 세션과 그 서브에이전트가 메인 체크아웃에 파괴적인 git 명령을 실행할 수 있던 문제를 막아 이제 모든 세션 유형에서 파일 편집과 Bash에 격리가 적용되고, PreToolUse 자동 허용 훅이 백그라운드 에이전트 작업(요약·컴팩션·이름 변경)에서 도구 제한을 우회하던 것도 고쳤어요. 네트워크 쪽으로는 HTTPS 프록시 뒤에서 시작 시 연결 확인이 멈췄다가 실패하던 문제를 API 요청과 동일한 프록시 인식 전송 방식으로 바꾸고 명확한 메시지와 함께 타임아웃되도록 해결했고, 실제로는 정상 완료된 응답에 "Connection closed mid-response" 오류가 표시되던 것도 수정됐어요. 그 밖에 Team·Enterprise 플랜에서 이전 요청이 반려(dismiss)된 멤버가 /usage-credits에서 "이미 요청을 보냈다"는 안내에 막혀 새 사용량 크레딧 요청을 못 보내던 버그, /usage가 MCP 서버 사용량을 과다 집계하던 문제(서버 호출 이후 모든 턴이 아니라 해당 서버의 도구 결과를 실제로 소비한 요청만 집계하도록 변경)도 바로잡았습니다.
