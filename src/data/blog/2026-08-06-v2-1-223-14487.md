claude CLI의 v2.1.223 업데이트예요. 관리형 설정 strictKnownMarketplaces와 blockedMarketplaces에 "owner/*" 형태의 오너 와일드카드 항목이 추가되어, 특정 GitHub 조직 아래의 마켓플레이스 저장소 전체를 한 번에 허용하거나 차단할 수 있게 됐습니다. 워크플로 에이전트·포크된 스킬·슬래시 커맨드·재개된 백그라운드 에이전트가 요청한 서브에이전트 모델이 제한되어 부모 모델로 대신 실행될 때 경고를 띄워주고, 클라우드 세션에서는 claude --teleport <session id>로 로컬에서 이어가는 방법을 알려주는 /teleport 힌트도 생겼어요. 보안 수정이 특히 많은데, 조작된 명령이 권한 검사에서 자기 일부를 숨길 수 있던 Bash 권한 우회, 탭이나 보이지 않는 유니코드로 승인 대화상자에서 명령 일부를 감추는 문제, 워크플로 스크립트가 dynamic import()로 샌드박스 밖 코드를 실행할 수 있던 구멍, 에이전트 정의의 bypassPermissions 모드가 조직의 bypass-permissions 비활성화 정책을 무시하던 권한 공백이 모두 고쳐졌습니다. 이 밖에 세션 도중 /cd 이후 세션 재개 관련 수정도 포함되어 있는데, 원문이 중간에 잘려 있어 해당 항목의 세부 내용은 확인이 필요해요.
