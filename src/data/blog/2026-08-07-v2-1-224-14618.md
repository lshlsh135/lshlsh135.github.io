Claude Code v2.1.224 릴리스 노트예요. 가장 큰 변화는 Team·Enterprise 플랜에서 `claude self-hosted-runner`로 내 머신이나 컨테이너를 Claude Code 웹·모바일·데스크톱 세션이 실행되는 환경으로 만들 수 있는 셀프 호스팅 기능이에요. 플러그인은 git이나 npm 없이 HTTPS로 zip 아카이브를 받아 설치할 수 있게 됐고, SHA-256 핀 고정 옵션도 함께 들어갔어요. Bedrock 사용자는 ANTHROPIC_BEDROCK_REGION_PREFIX 환경 변수로 AWS_REGION에서 유도되는 것 대신 원하는 크로스 리전 추론 프로필을 우선 지정할 수 있어요. 그 밖에 crossSessionInbound·dialogExpiry 설정이 추가돼 권한 우회(bypassed permissions) 상태로 도는 세션에 오는 크로스 세션 메시지는 승인 전까지 보류되고, JWT 인식 마스킹(decode: "jwt" + maskClaims)과 AWS SigV4 재서명(awsPairs/sigv4)을 포함한 샌드박스 자격 증명 마스킹 옵션도 생겼는데 이쪽은 network.tlsTerminate 설정이 필요해요.
