Claude Code v2.1.225 릴리스 노트예요. 사용량 경고에 게이트웨이 지출 한도(spend-limit) 지원이 추가돼서, 한도에 도달하면 메시지에 한도 금액·리셋 시각·운영자 메시지가 함께 표시되는데 게이트웨이도 2.1.225 버전이어야 해요. claude agents에도 신뢰되지 않은 디렉터리에 대한 워크스페이스 신뢰 프롬프트가 추가되어 claude와 동일하게 동작해요. 버그 수정으로는 일시적인 401 오류가 장기 유효한 CLAUDE_CODE_OAUTH_TOKEN을 짧은 수명의 저장된 로그인 토큰으로 바꿔치기해서 재시작 전까지 헤드리스 세션이 깨지던 문제, macOS에서 키체인 읽기 타임아웃 후 MCP OAuth 서버가 인증 안 된 것처럼 401을 연속으로 뱉던 문제가 고쳐졌어요. 그 외에 auto 모드가 자체 권한 확인에 대한 안전 필터 거부를 연속 차단 횟수에 잘못 집계하던 문제(동작은 여전히 거부되지만 이제 재시도 대신 넘어가도록 안내), 헤드리스 세션과 시작 중에 크로스 세션 메시지가 알림·만료 없이 대기 상태로 남던 문제도 수정됐어요.
