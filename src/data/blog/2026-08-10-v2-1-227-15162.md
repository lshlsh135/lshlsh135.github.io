Claude Code v2.1.227은 버그 수정 위주의 릴리스예요. 만료된 로그인 토큰으로 세션이 시작되면 구독 등급 정보 없이 기능 플래그가 평가돼서, Max 플랜 사용자에게 Fable 사용을 위해 usage credits를 켜라고 잘못 안내하던 문제가 고쳐졌어요. GitHub-hosted 러너에서 claude-code-action에 allowed_non_write_users를 설정하면 모든 Bash 명령이 실패하던 버그와, 첫 메시지 이전으로 되감은(rewind) 대화를 /tui가 다시 불러오던 문제도 수정됐고요. 슬래시 커맨드 메뉴는 선택된 행에만 파란색이 표시되고 매칭된 글자는 색 변경 대신 굵게 처리되며, 이모지나 악센트가 들어간 이름도 글리프가 깨지지 않게 개선됐어요. 성능 쪽으로는 file-not-found 제안과 at-mention 크기 체크에서 이벤트 루프가 멈칫하는 현상이 줄었습니다.
