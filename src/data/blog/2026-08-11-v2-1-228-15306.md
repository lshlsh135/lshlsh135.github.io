Claude Code v2.1.228은 버그 수정 위주의 패치 릴리스예요. 드문 내부 레이아웃 오류 후 프로세스는 살아 있는데 화면이 아예 다시 그려지지 않던 문제와, Windows에서 git 설치 경로의 상위 폴더에서 Claude Code를 실행하면 git/Git Bash를 못 찾던 문제가 고쳐졌어요. /model로 모델을 바꾼 뒤 /tui를 쓰면 세션이 이전 모델로 되돌아가던 버그, 그리고 Remote Control에서 연결 중에 /resume을 하면 재개한 대화의 제목이나 히스토리가 연결된 세션으로 새어 나가던 문제도 수정됐어요. self-hosted runner 쪽에서는 세션이 push하지 않는 저장소의 checkout 훅이 실패하면 매번 새 runner에서 세션 전체가 실패하던 것을 해당 저장소만 경고와 함께 건너뛰도록 바꿨고, 백그라운드 작업이 끝나고 다음 턴이 시작되기 전 틈에 세션이 종료되던 문제도 잡았어요. 이 밖에 설치·업그레이드 직후 첫 세션에서 크로스 세션 메시징이 inbox 없이 시작되던 문제와, 세션 정리(cleanup)가 프로젝트 memory 폴더 안의 내용을 삭제하던 문제도 함께 수정됐어요.
