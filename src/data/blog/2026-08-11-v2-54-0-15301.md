2026년 8월 11일에 나온 v2.54.0 릴리스 소식이에요. 기능 추가로는 api 영역에 새로운 Responses 모델 식별자(model identifiers)가 추가됐어요(#3595). 버그 수정으로는 오디오 업로드 시 메타데이터 요구사항을 명확히 정리했다고 해요(#3596). 그 외 잡무성 변경으로 자동 생성 파일 헤더의 저작 표기를 Castiron으로 업데이트했어요(#3583). 전형적인 마이너 버전 업데이트라 Responses 모델 식별자나 오디오 업로드 기능을 쓰는 경우가 아니라면 원문까지 열어볼 필요는 없어 보여요.
