Claude Code v2.1.229 릴리스에서는 가장 최근 Remote Control 세션을 이어가는 `claude remote-control --continue` 명령이 문서화됐고, 셀프호스티드 러너 세션에서도 관리형 환경과 동일하게 서버가 제공하는 Claude Code 훅을 지원하게 됐어요. 긴 thinking 구간 동안 Vertex·Bedrock 업스트림에서 유휴 타임아웃으로 연결이 끊기지 않도록 게이트웨이 스트리밍 응답에 SSE keepalive 핑도 추가됐고요. 플러그인 마켓플레이스에는 커맨드 소스가 생겨서, IDE 같은 로컬 명령이 플러그인 디렉터리를 출력하면 세션마다 다시 해석되어 재시작 없이 적용되고 mode: "link"를 쓰면 그 위치를 그대로 사용해요. ListAgents는 이제 연결이 끊긴 Remote Control 세션을 offline으로 표시하고 클라우드 세션에는 cloud 라벨을 붙여요. 버그 수정으로는 스트리밍 중 긴 응답이 일부 사라지거나 터미널에 두 번 출력되던 문제, 툴 호출의 glob·file_path·command 값이 문자열이 아닐 때(해당 세션 --resume 시 포함) 에러 화면으로 크래시하던 문제, 진행 바·마크다운 테이블 관련 RangeError 크래시가 해결됐어요.
