2026년 8월 12일 자 v3.0.0 릴리스인데, 호환성이 깨지는 변경(BREAKING CHANGE)이 포함되어 있어요. 이제 HTTPX2가 기본 HTTP 클라이언트가 되었고, 기존 httpx는 더 이상 자동으로 설치되지 않습니다. 커스텀 HTTPX 클라이언트, 트랜스포트, 설정 객체를 쓰고 있던 애플리케이션은 HTTPX2 대응 버전으로 마이그레이션하거나, 임시로 제공되는 런타임 전용 legacy HTTPX 우회 옵션(escape hatch)을 사용해야 해요. 자세한 전환 방법은 HTTPX2 마이그레이션 가이드를 참고하라고 안내하고 있습니다. 관련 변경 사항은 PR #3594(api: migrate to HTTPX2)로 반영되었어요.
