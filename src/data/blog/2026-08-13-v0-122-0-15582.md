2026-08-13에 나온 v0.122.0 릴리스예요. 기능 쪽에서는 API의 dream 생성에 output_behavior 옵션이 추가되어, 새 메모리 스토어를 만들지 아니면 입력한 스토어를 제자리에서 업데이트할지 선택할 수 있게 됐습니다. Bedrock/AWS 관련해서는 비동기 클라이언트에서 SigV4 서명을 이벤트 루프 밖에서 실행하도록 고쳤고, beta.messages.parse·stream·tool_runner가 노출됐어요. 클라이언트 버그 수정으로는 빈 ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN을 미설정으로 처리하고, copy() 이후에도 토큰 교환이 클라이언트별로 유지되며, 파일 튜플 안에 전달된 PathLike의 내용을 제대로 읽는 문제 등이 해결됐습니다. 스트리밍 쪽도 message_delta의 모든 필드를 누적 메시지에 반영하고, 서버 툴 사용 블록에 input_json 이벤트를 발행하며, 잘못된 툴 입력 JSON 오류에 컨텍스트를 추가하는 등 수정이 여럿 들어갔으니, SDK로 스트리밍이나 Bedrock 연동을 쓰고 있다면 업데이트를 확인해볼 만해요.
