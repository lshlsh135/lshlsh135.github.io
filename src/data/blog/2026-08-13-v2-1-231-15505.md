v2.1.231 버전이 나왔어요. 이번 릴리스에서는 MCP OAuth 로그인이 redirect URI 불일치(redirect URI mismatch)로 실패하던 문제가 수정됐어요. 특히 Slack처럼 미리 등록된(pre-registered) OAuth 클라이언트를 사용하는 서버에서 발생하던 문제라고 하네요. Slack 같은 MCP 서버에 OAuth 로그인이 안 돼서 막혔던 분들이라면 이번 버전으로 올려서 다시 시도해 보면 되겠습니다.
