Claude Code v2.1.232에서는 서브에이전트 포크가 기본으로 켜져서, subagent_type: "fork"로 생성한 서브에이전트가 전체 대화와 프롬프트 캐시를 그대로 물려받고, 인터랙티브 세션에서 팀메이트가 아닌 에이전트 생성은 이제 기본적으로 백그라운드에서 실행돼요. 프롬프트에 @를 입력하면 다른 Claude 세션을 이름으로 멘션할 수 있고 Claude가 SendMessage로 그 세션에 직접 연락하는데, 이름이 라이브 세션 하나와 정확히 일치하면 ref 확인 절차 없이 바로 전달됩니다. 한 머신 안의 인터랙티브 세션들은 고유한 이름을 유지하게 되어, 이미 다른 라이브 세션이 쓰는 이름으로 시작하거나 이름을 바꾸면 name-word-word 형태의 변형 이름이 자동으로 붙고 이를 알려줘요. 설정 쪽으로는 /config에 "Dialog expiry"와 "Messages from your other sessions"(다른 세션에서 오는 메시지 허용/보류/거부) 항목이 새로 생겼습니다. 보안 면에서는 GitLab 토큰 계열(glrt-, gloas-, glptt-, glagent-, glimt-, glsoat-, glcbt-, glft-, glffct-)의 시크릿 마스킹과 라우팅 가능한 glpat-/gldt- 토큰의 전체 마스킹이 추가됐고, glab CLI 설정 저장소에도 동일한 처리가 적용된다고 해요.
