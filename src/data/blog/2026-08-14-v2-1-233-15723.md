Claude Code v2.1.233 릴리스 노트예요. --worktree 플래그와 claude agents 화면에서 GitLab 머지 리퀘스트 URL을 지원하게 됐고(MR은 !N 형식으로 표시), Anthropic 업스트림에 옵트인 forward_user_identity 앱 게이트웨이 설정이 추가돼 로그인한 사용자의 신원을 헤더로 전달함으로써 게이트웨이 뒤의 프록시가 사용자별 지출을 집계할 수 있게 됐습니다. 리눅스에서는 CLAUDE_CODE_TOOL_MEMORY_LIMIT로 Bash 도구 명령에 메모리 cgroup 제한(옵트인)을 걸어 폭주하는 빌드가 세션을 멈추게 하는 걸 막을 수 있고, CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS 환경 변수로 WebFetch 세션 URL 캐시 TTL도 조정할 수 있어요(기본값 15분은 그대로). 버그 수정으로는 권한 프롬프트 대기 중에 환경이 종료되면 클라우드 세션이 유실(lost)로 표시되던 문제, 그리고 고정 타임아웃으로 장시간 스트림을 끊는 서버(예: 서버리스 호스트)를 상대로 MCP v2 연결이 subscriptions/listen 스트림을 끝없이 다시 여는 문제가 해결됐습니다.
