2026-08-14에 나온 v3.1.0 릴리스인데, API 쪽 기능 추가가 중심이에요. WebSocket 스트림 ID(#3612)와 workload identity 액세스 토큰 발급 이벤트(#3601)가 새로 들어갔고, Ultrafast 티어와 구조화된 MCP·WebSocket 에러, 분리된 WebSocket 이벤트(#3617)도 함께 추가됐어요. 주의할 부분은 Sora 비디오 API가 deprecated 처리됐다는 점(#3610)이라, 해당 API를 쓰고 있다면 대체 방안을 검토해야 해요. 그 외에 Stainless 관련 표기와 인프라를 제거하는 정리 작업(#3599)도 포함됐습니다.
