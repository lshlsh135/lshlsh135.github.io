Claude Code v2.1.234 업데이트로, 세션마다 별도 설정 디렉터리를 주는 호스트에서 프로젝트별 트랜스크립트 디렉터리 이름을 짧게 지정할 수 있는 선택형 환경 변수 CLAUDE_CODE_PROJECT_DIR_NAME과, 앱 안의 텍스트 선택을 키 하나로 해제하는 selection:clear 키바인딩 액션(에이전트 뷰에서도 동작)이 추가됐어요. GitLab 원격 저장소가 있고 glab CLI 인증이 되어 있으면 푸터와 상태줄에 MR !N 배지가 draft/pending/green 상태로 표시됩니다. claude.ai 사용량 제한이 리셋되면 세션이 자동으로 이어지는데, 원치 않으면 /config의 "Continue automatically at usage limit" 옵션에서 끌 수 있어요. 계정 이메일은 사용자 식별 용도로만 쓰고, 사용자가 요청하지 않는 한 무관한 서비스로 보내지 않도록 지침도 바뀌었습니다. 보안 강화로는 원격 파일 읽기, 세션 복원, CLAUDE.md include, 워크플로우 스크립트, 파일 업로드에서 Windows NT 네임스페이스(\??\) 경로를 거부하도록 했어요.
