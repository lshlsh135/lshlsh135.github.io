2026년 8월 18일 자로 나온 v3.3.0 릴리스예요. 핵심 기능 추가는 이름 있는(named) 데이터 레지던시 엔드포인트 지원(#3646)으로, 데이터가 머무는 리전을 지정된 엔드포인트로 사용할 수 있게 된 변경입니다. 버그 수정으로는 선택적(optional) 네트워킹 의존성에 대해 패치가 적용된 버전을 요구하도록 바뀌었고(#3651), 유지보수 차원에서는 안 쓰는 의존성 제거와 빌드 도구 버전 고정이 이뤄졌습니다(#3650). 문서 쪽에서는 Python SDK 보안 기여 가이드가 강화됐어요(#3639). 기능·수정 폭이 크지 않은 정기 릴리스라서, 데이터 레지던시 요구사항이 있거나 네트워킹 관련 선택 의존성을 쓰는 경우가 아니라면 급하게 올릴 필요는 없어 보입니다.
