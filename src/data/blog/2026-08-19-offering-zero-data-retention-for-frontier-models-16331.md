OpenAI가 자격을 갖춘 API 고객에게 제로 데이터 보존(Zero Data Retention, ZDR)을 계속 제공한다는 점을 재확인했어요. ZDR은 API로 주고받은 데이터를 OpenAI 측에 저장하지 않는 옵션이라, 민감한 데이터를 다루는 기업 고객에게 중요한 조건이죠. 여기에 더해 데이터 프라이버시를 해치지 않으면서 고급 AI 안전성 처리를 하겠다는 'Private Safety Processing'이라는 기능도 미리 공개(프리뷰)했어요. 원문 본문이 제공되지 않아 적용 대상 자격 요건이나 신청 방법 같은 세부 사항은 확인이 필요합니다.
