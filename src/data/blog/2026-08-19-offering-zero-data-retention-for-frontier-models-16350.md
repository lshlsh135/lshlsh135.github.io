OpenAI가 자격 요건을 충족하는 API 고객을 대상으로 프론티어 모델에 대한 Zero Data Retention(데이터 무보존) 정책을 재확인했어요. 말 그대로 API로 보낸 데이터를 OpenAI 쪽에 보존하지 않는 옵션을 계속 제공하겠다는 내용이에요. 함께 Private Safety Processing이라는 것도 프리뷰로 소개했는데, 데이터 프라이버시를 훼손하지 않으면서 고도화된 AI 안전 처리를 하겠다는 취지예요. 다만 어떤 고객이 '자격 요건'에 해당하는지, 신청 절차가 어떻게 되는지 같은 세부 내용은 이 발췌문에 없어서, 해당될 만한 API 고객이라면 원문에서 조건을 확인해야 해요.
