2026년 8월 18일 자 v0.123.0 릴리스 체인지로그예요(v0.122.0에서 업데이트). 기능 쪽에서는 files와 memory stores API에 항목이 추가되고, skill·files·user profiles API가 업데이트됐으며, 응답 헤더에서 workspace ID를 읽는 클라이언트 헬퍼가 새로 들어갔어요. 버그 수정으로는 지원되지 않는 mid_conv_system 콘텐츠 블록 제거, 서브프로세스 생성 없이 플랫폼 헤더 계산, ServiceUnavailableError와 DeadlineExceededError를 패키지 루트에서 export, session-runner가 tool-result 전송을 lease TTL 동안 재시도, 동기 세션 툴을 워커 스레드에서 실행하는 변경이 포함됐어요. 정리 작업으로는 구형 Text Completions API 예제와 남아 있던 prism 참조가 삭제됐으니, 해당 예제나 에러 임포트 경로에 의존하고 있었다면 확인해 보는 게 좋겠어요.
