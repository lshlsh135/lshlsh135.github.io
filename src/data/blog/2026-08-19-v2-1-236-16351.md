Claude Code v2.1.236 릴리스에서는 새 세션이 시작할 때 쓸 모델을 지정하는 ANTHROPIC_DEFAULT_MODEL 환경 변수가 추가됐는데, /model로 직접 고른 선택이 여전히 우선하고 재시작 후에도 유지된다는 점이 기존 ANTHROPIC_MODEL과 다릅니다. 크로스 세션 SendMessage에는 notify_when_idle이 생겨서 같은 머신의 다른 Claude Code 세션이 다음에 유휴 상태가 될 때 알림을 딱 한 번 보내도록 요청할 수 있어요(옵트인·원샷·폴링 없음, macOS와 Linux 지원). macOS 샌드박스에서는 **/.env 같은 와일드카드 읽기 차단 규칙이 허용된 읽기 영역 안에서도 우선 적용되고, 매칭된 디렉터리의 내용까지 커버하며, 차단된 파일의 이름을 바꿔도 우회할 수 없게 강화됐습니다. 버그 수정으로는 세션이 이동해 있던 디렉터리가 삭제된 뒤 클립보드 복사·백그라운드 하우스키핑·백그라운드 세션·로컬 MCP 로그가 깨지던 문제(2.1.229부터 발생)와, 풀스크린 렌더러가 한 번 시작에 실패하면 이후 실행마다 계속 종료되던 문제가 해결돼 이제는 클래식 렌더러로 폴백합니다. /model 선택 화면이 터미널 높이보다 크게 렌더링되던 문제도 고쳤다고 하는데, 이 항목은 원문이 중간에 잘려 있어 세부 내용까지는 확인되지 않습니다.
