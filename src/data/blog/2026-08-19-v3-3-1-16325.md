2026-08-19에 나온 v3.3.1은 보안 픽스가 공개된 의존성들을 일괄 업데이트한 유지보수 릴리스예요(#3680). 새 기능 없이 내부 정비 위주인데, 빌드 도구를 uv로 마이그레이션하고(#3653), jsonschema와 쓰지 않던 fixture-validation 의존성을 제거했으며, 저장소의 Pyright 툴체인을 버전 고정했어요(#3678). 이 밖에 mock 서버를 잠금된 로컬 툴링으로 실행하도록 바꾸고(#3679), 플랫폼 감지를 표준 라이브러리로 대체했으며, 외부 README 메타데이터 훅도 교체했습니다. 기능 변화는 없고 보안 의존성 업데이트가 핵심이라, 패치 적용 여부는 그 기준으로 판단하면 되는 릴리스예요.
