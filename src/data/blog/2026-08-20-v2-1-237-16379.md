Claude Code v2.1.237 릴리스 노트예요. LLM 게이트웨이나 커스텀 base URL을 쓰는 세션에서 프롬프트 캐싱이 제대로 동작하지 않던 문제가 수정됐어요. 새로 내장된 "Concise" 출력 스타일도 추가됐는데, 서론이나 진행 상황 나레이션을 생략하고 결과부터 먼저 보여주되 작업 자체는 똑같이 꼼꼼하게 수행하는 방식이에요. 이 스타일은 /config의 Output style 항목에서 선택할 수 있어요. 게이트웨이 경유로 Claude Code를 쓰면서 캐싱 비용 절감이 안 되던 분들과, 출력을 짧게 받고 싶은 분들이 챙겨볼 만한 업데이트예요.
