claude CLI v2.1.238 업데이트 소식이에요. 새로 생긴 keybindingFlavor 설정을 "readline"으로 두면 프롬프트에서 Ctrl+W가 Bash처럼 이전 공백까지 지워지고, 기본값 "classic"의 동작은 그대로예요. 플러그인 마켓플레이스에는 headersHelper가 추가돼서 url 마켓플레이스나 카탈로그 항목에 지정한 명령이 HTTP 헤더(예: 단기 토큰)를 발급해 카탈로그·동일 출처 아카이브 fetch에 쓰게 해 주는데, 카탈로그 항목의 headersHelper는 해당 플러그인을 설치/업데이트할 때만 실행되며 명령을 먼저 보여준 뒤 claude plugin install/update가 [y/N]로 확인을 받아요(-y로 생략 가능). 셀프 호스티드 러너 쪽에는 claude self-hosted-runner --defer-shutdown-max-min <minutes> 옵션이 생겨 SIGTERM을 받아도 연결된 세션을 계속 서빙하다가 지정한 시간이 지나면 남은 세션을 파킹하고 종료하고, 매 연결마다 새로 발급한 Proxy-Authorization 헤더가 필요한 이그레스 프록시용 --proxy-authorization-command / --proxy-authorization-file 옵션도 추가됐어요. 긴 인터랙티브 세션에서 메모리가 무한정 늘어나던 버그도 수정됐는데, 서브에이전트 도구 결과를 이제 해제한다는 내용에서 원문이 잘려 있어 정확한 해제 시점까지는 확인이 어려워요.
