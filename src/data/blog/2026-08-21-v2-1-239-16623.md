Claude Code v2.1.239 업데이트로, 비용 추정(/cost, 상태 표시줄, --max-budget-usd)이 데이터 레지던시 워크스페이스에 적용되는 1.1배 미국 전용 추론 프리미엄을 반영하게 됐습니다. Bedrock·Vertex·Foundry처럼 기존에 제외됐던 환경에도 풀스크린 렌더러 1회 제안이 추가됐고, 해당 환경의 신규 설치는 이제 풀스크린으로 시작합니다. Python 프로젝트를 anthropic 0.x에서 1.x로 마이그레이션해 주는 /claude-api upgrade 명령이 새로 생겼는데, 1.x에서는 타임아웃에 httpx.Timeout이 아니라 anthropic.Timeout을 사용한다는 점이 함께 반영됐습니다. 클라우드 세션에서는 claude.ai에서 동기화한 플러그인이 name@synced로 표시되고 claude plugin enable/disable <name>@synced 명령으로 켜고 끌 수 있으며, 직접 설치한 같은 이름의 플러그인을 덮어쓰지 않습니다. 그 밖에 Alpine/musl 빌드에서 이미지 붙여넣기·클립보드·오디오 캡처 네이티브 애드온이 정상 로드되도록 수정됐고, 월 지출 한도를 다 쓴 경우 세션·주간 한도 리셋 시점도 함께 안내되며, 프록시 환경에서의 Bedrock 스트리밍 관련 수정도 포함됐습니다.
