v2.1.243 릴리스에서는 /usage에 루프별 실행 횟수, 총 토큰, 실행당 토큰, 마지막 실행 시점을 보여주는 Loops 항목이 추가돼서 폭주하거나 토큰을 많이 쓰는 /loop 작업을 쉽게 찾아낼 수 있게 됐어요. modelPicker 설정으로 /model 선택 목록을 원하는 순서와 라벨로 직접 구성할 수 있고(Vertex/Bedrock 형식의 모델 id도 지원, 기본 목록에 추가하거나 통째로 교체 가능), promptCacheTtl과 subagentPromptCacheTtl 설정이 생겨서 API 키·클라우드 프로바이더 사용자는 메인 대화는 1시간, 서브에이전트는 5분으로 프롬프트 캐시를 따로 유지할 수 있습니다. 조직이 계약한 모델별 단가와 할인율을 반영하는 modelPricing 관리 설정도 추가돼 /cost, 상태 표시줄, 텔레메트리 비용이 정가 대신 실제 계약 요금으로 표시돼요. 마지막으로 API 키 발급을 허용하지 않는 조직을 위해 /login → Anthropic Console에 키 없이 Console 계정으로 로그인하는 옵션(권장)이 생겼고, /status에는 건너뛴 관리 설정 소스를 나열하는 Skipped sources 줄이 추가됐습니다.
