Claude Code v2.1.246 릴리스 노트예요. 서브커맨드 앞에 와일드카드가 들어간 Bash 허용 규칙(예: Bash(git * main))은 서브커맨드 앞에 끼워 넣은 옵션까지 매칭돼 버려서, 이런 규칙에 대해 시작 시 경고를 띄우도록 했고, /permissions에 Auto 모드 분류 규칙을 보고 편집할 수 있는 Auto 모드 탭도 추가됐습니다. 턴이 끝날 때 표시되는 소요 시간 줄에 완료 시각이 함께 나오게 됐어요(예: ✻ Sautéed for 23s · done 6:05 PM). diff에 base64 문자열처럼 아주 긴 한 줄이 있으면 트랜스크립트가 심하게 느려지던 문제는 해당 줄을 잘라서 표시 마커와 함께 렌더링하는 방식으로 해결했습니다. 그 밖에 풀스크린 모드에서 터미널 크기 조절 후 트랜스크립트가 빈 화면으로 나오던 버그, 이전 메시지 위치에서 스크롤이 튀거나 맨 아래로 이동이 중간에 걸리던 문제, 시작 디렉터리가 삭제됐거나 기기가 절전 상태였거나 프로세스 기동이 느린 호스트에서 백그라운드 세션이 45초 후 열리지 않던 문제도 수정됐어요.
