Claude Code v2.1.260 릴리스 노트예요. 전체화면 모드에서 대화 옆에 열리는 diff 패널이 추가돼 Claude가 편집하는 동안 커밋 안 된 변경사항을 바로 볼 수 있고, /diff 명령으로 켜고 끌 수 있어요. /cost와 상태 표시줄의 prompt_cache 필드에 프롬프트 캐시 미스의 추정 원인(도구 정의나 시스템 프롬프트 변경, TTL 초과 유휴 등)이 표시되고, /reload-plugins가 헤드리스 세션에도 추가돼 Claude Code Desktop과 SDK 명령 목록에 나타나요. 데스크톱 앱·Remote Control·헤드리스(-p/Agent SDK) 세션용으로 /advisor, /advisor <model>, /advisor off 텍스트 명령이 생겼고, Claude apps gateway에는 openid를 다시 요청해야 id_token을 주는 IdP를 위한 oidc.scope_on_refresh 옵션과 데스크톱 정책 블록의 userPluginMarketplacesEnabled·userPluginUploadsEnabled 키 지원이 들어갔어요. 경로에 괄호가 들어간 Edit/Write/Read 권한 규칙이 잘못된 규칙으로 취급돼 버려지거나 무시되던 문제도 수정됐어요.
