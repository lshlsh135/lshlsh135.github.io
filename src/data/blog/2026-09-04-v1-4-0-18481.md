2026-09-04에 나온 v1.4.0 릴리스로, 사용량 리포트(usage reports)에 Claude Tag 카테고리와 사용자별 분석이 추가됐고, 조직 컴플라이언스 설정 상태에 명명된 타입이 생겼으며, 더 많은 엔드포인트에서 workspace ID를 보낼 수 있게 됐어요. 버그 수정으로는 httpx2 객체 대신 httpx 객체를 넘기면 명확한 에러를 내도록 했고, messages 리소스의 커스텀 코드 머지 문제(#580)도 고쳤습니다. 그 외에는 예제의 플랫폼 모델 ID 갱신(#499), 목 서버 스펙 번들링과 개발 도구 업데이트, detect-breaking-changes 스크립트의 mypy unreachable 에러 수정, 코드오너 범위 조정(적용 후 되돌림), 오래된 테스트 경고 필터 제거 같은 내부 정리와 문서 문자열 소폭 업데이트예요. 사용량 리포트나 워크스페이스 단위로 API를 쓰고 있다면 업데이트할 만하고, 나머지는 내부 잡일이라 일반 사용자에게 체감 변화는 크지 않을 거예요.
