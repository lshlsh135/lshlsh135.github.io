Claude Code v2.1.266은 2.1.265에서 생긴 LLM 게이트웨이·프록시 설정 관련 회귀 버그를 고친 릴리스예요. 문서화되지 않은 CLAUDE_CODE_USE_GATEWAY 환경 변수는 원래 ANTHROPIC_BASE_URL과 ANTHROPIC_AUTH_TOKEN이 둘 다 설정된 경우에만 동작했는데, 2.1.265부터는 이 변수 하나만으로도 Cloud 게이트웨이 로그인을 강제하도록 바뀌어 버렸어요. 그래서 이 변수를 API 키, apiKeyHelper, 커스텀 인증 헤더와 함께 쓰던 환경에서는 모든 요청이 "Not signed in to the Cloud gateway" 오류로 실패했죠. 이번 버전에서는 이 변수가 단독으로 설정된 경우 다시 무시되므로, 2.1.265에서 해당 오류를 겪었다면 별도 설정 변경 없이 업데이트만 하면 됩니다.
