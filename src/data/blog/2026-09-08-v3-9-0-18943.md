2026년 9월 5일자 v3.9.0 릴리스 노트로, API 쪽 기능 추가와 버그 수정, 잡일성 변경이 함께 들어갔어요. 새 기능으로는 프롬프트 캐시 진단(prompt cache diagnostics, #3800)이 추가됐고, 함수 인자 완료(function argument completion) 이벤트의 필드가 OpenAPI 스펙(openapi-545)에 맞게 수정됐어요(#3801). 버그 수정으로는 불완전한 웹 검색 호출 상태(incomplete web search call statuses)를 그대로 받아들이도록 바뀌었고(#3786), 서버가 보내는 재시도 지연 값이 오버플로우하는 경우 거부하도록 고쳤어요(#3799). 그 외에 스로틀링과 모델 과부하(model overload) 응답에 대한 문서화(SDK-235, #3803), 그리고 포크된 steady로의 마이그레이션(#3795)이 포함됐어요. 본문이 없어서 어떤 SDK인지, 각 변경의 세부 동작이나 실제 사용법은 원문 릴리스 노트를 확인해야 해요.
