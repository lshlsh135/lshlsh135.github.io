2026년 9월 8일자 v3.10.0 릴리스로, 이번엔 API 쪽 기능 추가 두 건이 핵심이에요. 먼저 GPT Image 2.5 모델과 함께 이미지 관련 옵션(image options)이 API에 새로 추가됐어요(#3824, 5b39c45). 그리고 서비스 계정(service-account) API 키에 만료(expiration) 관련 필드가 생겨서, 키 만료 정보를 API 응답에서 다룰 수 있게 됐어요(#3802, f1cd7f0). 이미지 생성 기능을 쓰거나 서비스 계정 키를 관리하는 쪽이라면 업데이트 후 새 모델 옵션과 만료 필드를 확인해보면 좋겠어요. 다만 구체적인 파라미터 이름이나 사용 예시는 이번 변경 내역에 포함되어 있지 않아요.
