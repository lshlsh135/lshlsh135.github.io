2026년 9월 9일에 3.11.0 버전이 릴리스됐어요. 이번 릴리스의 주요 기능은 api 영역에서 서비스 계정 키(service account key)에 만료(expiration) 제어 기능이 추가된 점이에요(#3825, 커밋 f348ec8). 즉 서비스 계정용 키에 만료 시점을 설정해서 관리할 수 있게 된 것으로 보이는데, 구체적인 설정 방법이나 옵션 이름은 릴리스 노트 요약에 나와 있지 않아요. 서비스 계정 키를 발급해서 운영 중이거나 키 수명 주기 관리가 필요한 팀이라면 이슈 #3825 내용을 확인해 볼 만해요.
