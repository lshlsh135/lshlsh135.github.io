2026년 9월 10일자 SDK 릴리스 v1.5.0의 체인지로그로, v1.4.0 이후 변경 사항을 정리했어요. API 쪽에서는 Managed Agents용 auto mode 도구 권한, web_fetch 도구의 content_too_large 에러 코드, user-profiles-2026-09-04 베타 값과 external_user_details 필드, 그리고 authorization_token 없이 공개 GitHub 저장소를 Managed Agents 세션에 마운트하는 기능이 추가됐습니다. 클라이언트 쪽에서는 Message.to_param()과 BetaMessage.to_param()이 생겼고, messages.create·parse·stream·count_tokens에 tool 객체를 직접 넘길 수 있게 됐으며, CredentialsError와 IdentityTokenFileError 예외가 추가됐어요. 버그 수정으로는 extra_body를 클라이언트 훅 실행 전에 병합하고, 스트리밍 중 부분적인 tool input JSON이 content block에 섞이지 않도록 하며, 덤프된 텍스트 블록에서 parsed_output을 제외하고, 그룹이나 다른 사용자가 접근 가능한 credentials 파일은 거부하도록 바뀌었습니다. 특히 credentials 파일 권한 검사가 엄격해졌으니 업그레이드 전에 파일 퍼미션을 확인해 두는 게 좋겠어요.
