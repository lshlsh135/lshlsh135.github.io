Claude Code v2.1.268 릴리스예요. 이번 버전은 주로 Claude 앱 게이트웨이와 관리자 기능이 보강됐어요. gateway.yaml에 pricing: 을 설정하면 로그인된 Claude Code 클라이언트가 managed settings를 통해 같은 요금을 받아서, /cost 출력과 텔레메트리가 지출 미터와 일치하게 됐고요. access_control.allow_cidrs가 비어 있으면 게이트웨이 시작 시 경고를 띄우고, 공용 주소에서 첫 요청이 들어오면 한 번 경고를 표시해요. 새 gatewayInternalNetworks managed setting으로 조직 소유 공용 IPv4 대역에서 게이트웨이로 /login 하는 걸 관리자가 허용할 수 있어요. 그 밖에 claude self-hosted-runner --remove-session-state 옵션(기본 off)으로 세션 종료 시 <base-dir>/_sessions/ 아래 세션별 디렉터리를 삭제할 수 있고, claude auth status --json 출력에 configDirectory가 추가됐으며, claude plugin install/uninstall/update/enable/disable에 --json 플래그와 claude plugin list --json 각 행에 errorDetails/noteDetails가 붙었고, 게시된 아티팩트에 Claude가 페이지에 맞춰 고른 브라우저 탭 아이콘이 생겼어요. 발췌문이 중간에 잘려 있어서 수정된 버그 목록은 확인되지 않아요.
