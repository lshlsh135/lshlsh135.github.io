v3.12.0이 2026년 9월 10일자로 릴리스됐어요. 기능 추가로는 api 영역에 Live API가 새로 들어간 게 핵심이에요. 버그 수정으로는 AsyncStream에 aclose()가 추가돼서 표준 async 정리 패턴을 쓸 수 있게 됐고, 타입 인자 없는 bare dict / list 어노테이션을 처리하지 못하던 문제(#3760)와 null 응답 완료 시 최종 출력이 사라지던 문제(#3345)가 고쳐졌어요. 릴리스 노트에 상세 본문이 없어서 Live API의 구체적 사용법은 원문 저장소 문서를 확인해야 해요.
