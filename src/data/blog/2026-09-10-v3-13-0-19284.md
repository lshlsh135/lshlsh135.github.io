v3.13.0 릴리스가 2026년 9월 10일자로 나왔어요. 이번 버전의 핵심 변경은 api 영역에 Agents API가 추가된 것이고, 관련 커밋은 1c4284a입니다. 릴리스 노트에 공개된 내용은 이 기능 항목 하나뿐이라 Agents API의 세부 사용법이나 파라미터는 아직 확인되지 않았어요. Agents 관련 기능을 API로 다루려던 분들은 이 버전의 변경 사항을 직접 확인해 보시면 좋겠습니다.
