Claude Code v2.1.269가 나왔고, 이번 버전은 새 기능이 꽤 많이 실린 릴리스예요. 먼저 claude plugin eval 명령이 추가돼서 플러그인의 eval 스위트를 Claude Code에 돌리고 JSON과 HTML 리포트로 점수화된 재현 가능한 결과를 받을 수 있고, 자세한 사용법은 claude plugin eval --help로 확인하면 됩니다. /output-style [name] 커맨드로 출력 스타일을 목록 조회하고 전환할 수 있는데, Remote Control이나 클라우드, 기타 headless 세션에서도 동작해요. Bash 도구가 파일 편집을 처리하는 경우 그 명령이 바꾼 파일의 diff가 Bash 도구 결과에 같이 붙도록 바뀌었고, 이는 bashEditDiffEnabled 설정으로 제어합니다. 운영 쪽으로는 OTEL_METRICS_INCLUDE_REPOSITORY로 OpenTelemetry 메트릭과 이벤트에 vcs.* 저장소 속성을 태깅할 수 있고 OTEL_LOG_TOOL_DETAILS를 켜면 커밋 이벤트에 vcs.ref.head.* 정보가 실리며, CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS로 LLM 게이트웨이의 /v1/models 탐색 타임아웃(기본 3초)을 늘릴 수 있고, CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS(1~256)로 Workflow 도구의 실행당 동시 에이전트 상한을 올려 추론 위주의 fan-out 작업에 대응할 수 있어요. 그 밖에 프롬프트·한 줄 작업 요약·응답만 보이는 /focus 뷰를 안내하는 스피너 팁도 추가됐습니다.
