Claude Code v2.1.271은 원격 세션과 설정 UI, 샌드박스 권한 쪽에 작은 편의 기능을 여러 개 얹은 업데이트예요. Claude Code Remote 세션(클라우드·자체 호스팅 러너)에서 fast mode를 쓸 수 있게 됐는데, 호스트의 fast-mode 설정이나 세션에서 입력한 /fast가 조직이 허용하는 범위 안에서 적용돼요. 전체 화면 모드의 /config 패널에는 마우스 지원이 들어가서 휠로 설정 목록을 스크롤하고, 설정 값을 클릭해 바꾸고, 포인터가 올라간 행이 하이라이트돼요. 샌드박싱을 쓰는 auto 모드에서는 Bash·PowerShell·Monitor에 per-command allowed_domains가 생겨서 해당 명령에 필요한 호스트만 그 명령 한정으로 열리고 나머지 호스트는 거부되고요. 이 밖에 에이전트 frontmatter와 --agents JSON의 omitClaudeMd(사용자·프로젝트·로컬 CLAUDE.md 없이 커스텀/플러그인 서브에이전트 실행, 관리형 정책 파일은 그대로 로드), claude self-hosted-runner --drain-marker-file <path>(SIGTERM drain 시 해당 파일이 있으면 호스트 drain으로 보고, 텔레메트리 전용), claude plugin install의 --accept-command <sha256>가 추가됐는데, 원문 발췌가 중간에 잘려 있어 나머지 항목은 릴리스 노트를 직접 확인하는 게 좋아요.
