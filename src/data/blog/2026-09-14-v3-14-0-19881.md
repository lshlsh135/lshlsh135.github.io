OpenAI 공식 SDK의 3.14.0 릴리스(2026-09-14)로, 새 기능보다는 스트리밍·에러 처리 쪽 안정화가 중심이에요. 기능 항목은 스트림을 읽는 도중 발생한 에러를 표준화해서 던지도록 바꾼 streaming 개선(#3827) 하나입니다. 버그 수정은 벡터 스토어 파일 폴링 바인딩 문제(#3401), 파일 업로드 시 PathLike 튜플 정규화(#3475), 콘텐츠 필터 에러에 completion 포함(#3094), OPENAI_LOG 환경변수의 표준 로그 레벨 지원(#3734), API 에러 코드를 문자열로 정규화(#3532, #3531 종료), 빈 아이템 이후 응답 스트림 인덱스 유지(#3126), responses의 output_text가 null일 때 처리(#3019) 등이 들어갔어요. 에러 코드가 문자열로 통일된 점은 코드 값을 숫자로 비교하던 기존 코드가 있다면 확인이 필요한 부분입니다. 그 외에 realtime push_to_talk_app 예제의 세션 타입 갱신(#2926)과 README 예제에서 비전 가이드 이미지를 쓰도록 한 문서 수정(#3849)이 포함됐습니다.
