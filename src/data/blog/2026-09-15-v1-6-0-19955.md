Anthropic SDK 1.6.0이 2026년 9월 15일에 나왔습니다. 새 기능 쪽은 Managed Agents용 auto 모드 도구 권한, 베타로 들어온 compaction 파라미터와 서명된 compaction 블록, 웹 fetch 도구의 url_sources, 사용자 프로필 메서드의 workspace_id 파라미터, 워크스페이스 데이터 레지던시 geo 필드용 enum 타입, 그리고 베타 input_transformations의 thinking_mismatch_allowed 항목이 추가됐고, 클라이언트는 비동기 credential 토큰 프로바이더를 지원하게 됐습니다. 버그 수정은 재시도 로직에 몰려 있는데, 60초를 넘는 Retry-After 값을 그대로 존중하고, 잘못된 Retry-After는 무시하면서 maxRetries를 검증하고, 범위를 벗어난 값은 기본 백오프로 되돌리도록 바뀌었습니다. 또 async 클라이언트에서 연결 오류를 재시도하고 코루틴 재시도 루프가 블로킹하지 않도록 고쳤으며, usage 순회의 model을 nullable로 표시하고 message와 delta 이벤트가 하나의 input transformation 타입을 쓰도록 정리했습니다. 비동기 클라이언트로 대량 호출을 돌리며 429/503 재시도 동작에 민감한 쪽이라면 올려볼 만한 버전입니다.
