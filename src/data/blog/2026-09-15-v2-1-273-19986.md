이번 v2.1.273에서는 LLM 게이트웨이용 요청 헤더 다섯 개(x-claude-code-request-class, x-claude-code-agent-type, x-claude-code-prev-tool-durations, x-claude-code-compaction, x-claude-code-context-compacted)가 추가됐는데, 기본으로 켜지는 건 아니고 CLAUDE_CODE_GATEWAY_HINT_HEADERS=1로 직접 opt-in 해야 합니다. MCP 서버가 세션 도중에 끊기고 자동 재연결도 포기한 경우 이제 알림이 뜨면서 /mcp로 안내해 주고, claude --remote-control이나 /remote-control로 시작한 세션은 Claude 앱에서 포크할 수 있게 됐습니다(포크된 세션은 내 컴퓨터에서 백그라운드 세션으로 돕니다). 보안 쪽 수정이 눈에 띄는데, 권한 검사기가 완전히 분석하지 못하는 Bash 명령이 permissions.blockReadsOutsideWorkingDirectories 설정에서 확인 프롬프트를 건너뛰던 문제와, bypass 모드에서 서브셸 안에 숨은 위험한 rm이 걸러지지 않던 문제가 함께 고쳐졌습니다. 또 조직이 Skills를 꺼도 claude.ai에서 동기화된 스킬이 계속 남아 있던 문제가 수정돼 이제는 복구 가능한 휴지통으로 옮겨지고, MDM이나 managed-settings.json으로 설정한 allowManagedMcpServersOnly·deniedMcpServers·disableClaudeAiConnectors가 무시되던 문제도 처리됐습니다. 게이트웨이를 끼고 쓰거나 MDM으로 팀 설정을 관리하는 환경이라면 한 번 올려둘 만한 릴리스입니다.
