OpenAI Python SDK의 3.14.1 패치 릴리스(2026-09-15)로, 새 기능 없이 버그 수정과 문서 정리 위주입니다. 클라이언트 쪽에서는 재시도 한도(retry limit) 검증이 추가되고 애플리케이션 에러가 그대로 보존되도록 고쳐졌으며(#3867), Live WebSocket 진단 로그는 본문 대신 메타데이터만 남기도록 바뀌었습니다(#3865). responses 쪽은 commentary에 대해 structured parsing을 건너뛰도록 수정됐고(#3861), StreamAlreadyConsumed 에러 메시지의 오타("th" → "the")도 정리됐습니다(#3022). 예제 코드도 손봤는데 Azure 엔드포인트 호스트명 수정(#3298), chat streaming 예제 갱신(#2974), push-to-talk shebang 인자 분리(#3210), 남아 있던 Python 런처를 uv로 통일(#3821), module_client.py의 모델을 gpt-5.6으로 올린 변경(#3211)이 포함됩니다. 이 외에 쓰이지 않던 파인튜닝 데이터 검증기가 제거됐고(#3863), async 클라이언트 정리 방법과 인메모리 파일 업로드 시 파일명 처리에 대한 문서 설명이 보강됐습니다.
