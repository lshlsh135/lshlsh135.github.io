Claude Code v2.1.275는 로그인 확인, 메시지 전송, 계정 동기화 쪽 편의 기능을 묶은 업데이트예요. Claude apps 게이트웨이 로그인에서 게이트웨이가 계정 이름을 알려주면 자격 증명이 저장되기 전에 사용자가 직접 확인하게 됐고, 어떤 계정으로 로그인됐는지는 /status에서 볼 수 있어요. 또 ctrl+enter(또는 ctrl+x ctrl+s)로 현재 턴을 중단하고 대기 중인 메시지를 한꺼번에 보내는 즉시 전송 키가 생겼는데, 보낸 메시지와 대기 메시지는 모델이 받기 전까지 회색으로 표시돼요. claude.ai 계정에서 켜둔 스킬·플러그인이 같은 계정으로 로그인한 터미널 세션에도 동기화되며 원치 않으면 syncClaudeAiSkills: false / syncClaudeAiPlugins: false로 끌 수 있고, /plugin install <plugin> --marketplace <source>는 플러그인 설치 전에 마켓플레이스 추가를 먼저 제안해요. 이 밖에 otelHeadersHelper가 실패하면 시작 시 경고를 띄워 텔레메트리가 조용히 안 나가는 상황을 알아채게 했고, 컴팩션이나 재개 후 복원된 메모리 파일의 age 표기가 요청마다 바뀌어 프롬프트 캐시가 깨지던 문제도 고쳤어요.
