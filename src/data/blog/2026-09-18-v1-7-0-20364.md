2026년 9월 18일에 나온 1.7.0 릴리스는 API 쪽에서 rate limit에 display_name을 가진 group을 추가하고 기존 group_type을 deprecate했으며, 툴 러너에 compact_before_next_turn()이 새로 들어왔어요(#641, 이후 #804에서 상태 관리와 실패 처리 정리). 버그 수정으로는 bedrock에서 eventstream 예외·에러 프레임을 만나면 API 에러를 던지도록 바뀌었고(#769), 응답 파싱 시 X | Y 유니온 타입을 받아들이고 알 수 없는 데이터가 와도 TypeError를 내지 않게 됐어요. 또 anthropic-beta 값이 여러 개일 때 공백 없이 콤마로만 이어붙이도록 수정됐습니다(#781). 의존성 쪽은 pydantic 1.10 이상을 요구하도록 올라갔으니 업그레이드 전에 확인이 필요하고, 문서에는 enum 값·path 파라미터 설명과 compaction의 tool_changes 관련 설명이 보강됐어요. group_type을 쓰고 있다면 group + display_name으로 옮길 준비를 해두는 게 좋겠습니다.
