이번 릴리스에서 가장 눈에 띄는 건 AGENTS.md 지원입니다. CLAUDE.md가 없는 프로젝트라면 Claude Code가 대신 AGENTS.md를 읽고, 이 동작은 /config의 "Project instructions"에서 바꿀 수 있어요 (단 Bedrock·Vertex·Foundry에서는 아직 안 됩니다). 기업 환경을 위한 옵션도 추가됐는데, 외부로 나가는 경로가 포워드 프록시뿐인 Claude apps 게이트웨이라면 CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1을 켜서 호스트명을 로컬에서 resolve하지 않고 프록시에 넘기도록 할 수 있고, 게이트웨이 upstream에 선택적 headers: 맵을 두어 프로바이더 앞단 프록시로 고정 헤더를 보낼 수도 있습니다. 버그 수정도 꽤 실용적입니다. 내부 오류 후 결과 없이 멈춰 있던 claude -p와 Agent SDK 세션이 이제 오류를 보고하고 exit code 1로 종료하고, 이전 어시스턴트 턴에 빈 텍스트 블록이 섞여 있을 때 --resume 이후까지 모든 요청이 "text content blocks must be non-empty"로 실패하던 문제도 고쳐졌습니다. 그 외 /tasks 같은 패널을 열어둔 상태에서 백그라운드 작업이 끝나면 업데이트가 대기 중이라는 안내 줄이 표시되고, 예기치 않게 로그아웃되던 문제도 수정됐습니다.
