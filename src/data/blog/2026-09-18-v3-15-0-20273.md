OpenAI 공식 SDK의 3.15.0 릴리스(2026-09-18)로, 기능 추가 5건과 버그 수정 1건이 담긴 소규모 업데이트예요. 새 기능으로는 에이전트 세션 모델 설정(#3882), audio-mini 모델 선택지 추가(#3886), 컴팩션 진행 상황 이벤트(#3866), 관리형 Responses WebSocket 세션(#3887), 프롬프트 캐시 프리워밍(#3888)이 들어갔습니다. 버그 수정은 채팅 스트림의 모더레이션 결과가 유실되지 않도록 보존하는 항목(#3864) 하나예요. 이 외에는 SIP 수신 통화 ID 사용법 명확화, 이미지 요청 예제 갱신 같은 잡무성 변경과 realtime 문서에서 존재하지 않는 타입 import를 제거한 문서 수정이 포함됐습니다. 릴리스 노트에 커밋 해시와 PR 번호만 나와 있고 실제 코드 예시나 마이그레이션 안내는 없으니, 프롬프트 캐시 프리워밍이나 WebSocket 세션 API를 쓰려면 해당 PR이나 공식 문서를 따로 확인하는 게 좋아요.
