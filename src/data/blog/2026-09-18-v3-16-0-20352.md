2026년 9월 18일자 3.16.0 릴리스로, 변경 사항은 기능 추가 하나와 정리 작업 하나로 단출합니다. 기능 쪽에서는 api에 웹훅 엔드포인트 관리(webhook endpoint management) 기능이 들어갔습니다(#3892, 커밋 9a11f6e). 정리 쪽에서는 api의 MCP connector_id가 deprecate 처리됐습니다(#3894, 커밋 1ccaf07). 즉 웹훅 엔드포인트를 코드에서 직접 등록·관리하고 싶었던 사람에겐 반가운 업데이트이고, 반대로 MCP connector_id에 의존하는 코드가 있다면 지금부터 대체 경로를 알아봐야 한다는 신호입니다. 다만 이번 입력에는 릴리스 노트 요약만 있고 실제 메서드명이나 파라미터, 마이그레이션 가이드가 포함되어 있지 않아서, 구체적인 사용법은 해당 PR과 공식 문서를 확인하는 편이 좋습니다.
