1.8.0(2026-09-22) 릴리스의 하이라이트는 api 쪽 신규 기능이에요. claude-opus-5-5 지원과 함께 인라인 tool 정의, MCP tool-list 고정(pinning)이 베타로 추가됐습니다(b5cc700). 버그 수정도 쓸모 있는 게 몇 개 있는데, Python 3.13에서 스트림을 열어둔 채 종료할 때 나던 크래시가 잡혔고(af029bd), add_tools() 호출이 곧바로 반영되도록 고쳐졌으며(#874, 06d0a6b), tool 러너의 compaction 요청에서 reply-only 파라미터를 빼도록 정리됐어요(#871, 4687310). Managed Agents 이벤트들이 evaluated_permission enum 하나를 공유하게 된 것도 변경점입니다(f4f51c8). 나머지는 Dreams API·User Profiles API 레퍼런스 설명 추가, Managed Agents의 memory store 설명 보강, beta messages의 diagnostics 필드 설명 갱신 같은 문서 작업과 mypy 제거·테스트 픽스처 업데이트 같은 내부 정리라 실제 동작에 미치는 영향은 적습니다.
