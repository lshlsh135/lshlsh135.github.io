Claude Opus 5.5(claude-opus-5-5)가 추가되면서 기본 Opus 모델이 되었고, 1M 컨텍스트에 100만 토큰당 입력 $4 / 출력 $20, 캐시 읽기는 $0.20 가격이 매겨졌어요. 전체화면 모드의 마우스 지원도 넓어져서 /skills 목록을 휠로 스크롤하고 /plugin에서 스킬 상태 옵션을 클릭할 수 있게 됐고, CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH 환경변수로 세션 내 모든 MCP 서버의 툴 설명·서버 지침에 걸려 있던 2,048자 제한을 조정할 수 있어요. 관측 쪽에서는 hook_execution_complete OpenTelemetry 이벤트에 훅 출력 크기와 파일로 저장된 초과 출력 개수가 함께 실려요. 버그 수정으로는 심볼릭 링크 경로를 통한 쓰기가 트리 안 경로 표기만 보고 판단되던 문제가 잡혀서, 프롬프트가 실제로 파일이 떨어지는 위치를 알려주고 acceptEdits·allow 규칙·자동 모드가 트리 밖에 떨어지는 쓰기를 승인하지 않게 됐어요. 또 안전 검사가 검토를 거부했을 때 자동 모드가 같은 동작을 무한 재시도하던 문제도 고쳐져, 이제 한 번 거부하면서 재시도해도 소용없다는 점을 알려줍니다.
