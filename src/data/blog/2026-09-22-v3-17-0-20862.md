2026년 9월 22일에 나온 3.17.0 릴리스로, API 쪽 기능 추가가 중심이에요. 외부 스토리지 설정 관리(#3909), 세이프티 케이스 조회(#3911), 세이프티 경고·비활성화 웹훅 이벤트(#3908), 세션 환경 리셋 이벤트(#3913), 수신 통화 이벤트의 SIP 미디어 보안(#3907), 그리고 환경변수 기반 vault 자격증명 지원(#3905)이 들어갔습니다. 버그 수정으로는 모델 타입과 네트워크 정책 문서 정정, 모델 선택값 보존 및 에러 응답 문서 연기(#3931), parse_response에서 null 메시지 콘텐츠를 빈 값으로 처리(#3851), 그리고 deprecated된 log.warn 대신 log.warning 사용(#3878)이 포함됐어요. 나머지는 API 에러 응답 계약 문서화(#3917), 응답 관리 리소스 문서화(#3912) 같은 문서 작업과 actions/github-script 7.1.0→9.0.0, actions/upload-artifact 5.0.0→7.0.1 등 의존성 범프입니다. 웹훅 이벤트를 직접 처리하거나 vault 자격증명을 쓰는 쪽이라면 확인해볼 만한 릴리스예요.
