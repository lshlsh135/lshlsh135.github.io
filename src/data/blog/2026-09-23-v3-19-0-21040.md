2026년 9월 22일 배포된 3.19.0에서는 기능 두 가지가 추가됐어요. GCP 외부 스토리지 지원(#3943)이 들어왔고, GPT-Rosalind 리서치 모델(#3940)을 쓸 수 있게 됐습니다. 버그 수정 쪽은 비동기 처리와 네트워크 안정성에 몰려 있는데, `_async_transform_recursive`에서 `api_exclude`가 제대로 전달되지 않던 문제(#3324), 큐에 쌓인 WebSocket 이벤트의 생략 마커(omission marker) 처리(#3944), 재시도 시 재전송 가능한 요청 본문만 다시 보내도록 고친 부분(#3771)이 포함됐어요. 여기에 구버전 aiohttp가 설치된 환경도 허용하도록 완화(#3941)하고, async 메서드 내부에서는 `asyncio.get_running_loop()`를 쓰도록 바꾼 수정(#3289)도 들어갔습니다. 릴리스 노트 수준의 정보만 공개돼 있어서, 실제 사용법이나 마이그레이션 영향은 각 PR을 직접 확인하는 편이 좋아요.
