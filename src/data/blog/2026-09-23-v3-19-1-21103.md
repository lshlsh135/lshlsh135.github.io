v3.19.1은 2026-09-23에 나온 버그 수정 위주의 패치 릴리스예요. chat 쪽에서는 한 번만 순회할 수 있는 tool iterable이 그대로 유지되도록 고쳤어요(#3770). client 쪽에서는 HTTP 헤더를 합칠 때 대소문자를 구분하지 않도록 바뀌었어요(#3486). 그 밖에 api 문서에서 Chat Completions의 seed 제한 설명을 더 분명하게 다듬었고(#3945), 협업자만 pull request를 올릴 수 있다는 정책도 문서에 명시했어요(#3948).
