v3.19.2는 2026-09-23에 나온 패치 릴리스로, 버그 수정 1건과 API 관련 정리(Chores) 몇 건이 들어갔어요. 버그 수정은 폴백 추출 경로에서 단일 파일이 제대로 보존되도록 고친 내용이에요 (#3875). 나머지는 API 쪽 정리 작업이에요. 웹 검색의 대략적 위치(approximate location) 기본값 설명 보강(#3953), Realtime의 modality 배열 정의 명확화(#3954), 파인튜닝 값 범위와 Realtime 응답 참조 수정(#3949)이 포함됐어요. 새 기능은 없고 버그 수정과 정의 정리 위주라서, 폴백 추출 경로를 쓰고 있다면 업데이트해 두는 게 좋아요.
