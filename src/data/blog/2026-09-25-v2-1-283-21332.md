Claude Code v2.1.283에서는 관리자용 모델 제어 설정이 늘었어요. availableModelsMatch를 "exact"로 두면 availableModels에 적은 모델 버전만 허용되고, 새 버전은 목록에 추가하기 전까지 막혀요. 새로 생긴 deniedModels는 availableModels에서 허용된 모델이라도 따로 차단할 수 있게 해 줘요. LLM 게이트웨이 쪽에서는 CLAUDE_CODE_GATEWAY_HINT_HEADERS=1로 켜면 x-claude-code-prompt-id 헤더가 붙어서, 사용자 프롬프트 하나에서 나간 요청들을 묶어 볼 수 있어요. 그 밖에 OTEL_LOG_TOOL_CONTENT=1일 때 MCP 도구, WebFetch, WebSearch 출력도 OpenTelemetry tool.output 이벤트에 기록되고, /doctor prompt-audit(/checkup prompt-audit)로 CLAUDE.md, 스킬, 에이전트, 커맨드에 예전 모델용 프롬프트 패턴이 남아 있는지 점검할 수 있어요.
