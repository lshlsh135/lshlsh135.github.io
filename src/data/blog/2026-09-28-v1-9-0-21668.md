2026-09-28에 v1.9.0이 나왔어요(v1.8.0 대비). 새 기능으로는 between_tools thinking 타입이 생겼고, 모델 ID claude-sonnet-5-5가 추가됐어요. 워크스페이스 rate limit에는 include_inherited와 source가 붙었고, Managed Agents 이벤트 목록 필터에서도 타입이 지정된 이벤트 타입 값을 쓸 수 있게 됐어요. 캐시 진단(cache diagnostics)은 GA가 돼서 Message와 MessageCreateParams에 diagnostics가 들어가고, 응답이 스트리밍되는 동안 툴 호출을 실행하는 옵션도 새로 생겼어요. 버그 수정도 몇 가지 있어요. 이름 없는 파일을 업로드할 때 임시 파일명(placeholder)을 더 이상 보내지 않고, fallback 단계에서는 between_tools thinking이 disabled로 내려가요. stream()과 parse()도 이제 diagnostics를 받아요. 그 밖에 parse와 tool runner가 beta 헤더를 보내지 않도록 바뀌었고, stream: true가 원시(raw) 이벤트 스트림을 돌려준다는 점을 문서에 더 분명하게 적었어요.
