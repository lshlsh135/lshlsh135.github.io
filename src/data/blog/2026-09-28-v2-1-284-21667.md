Claude Code v2.1.284에서는 Claude Sonnet 5.5(claude-sonnet-5-5)가 추가됐고, 이제 Anthropic API의 기본 Sonnet 모델이에요. 컨텍스트는 1M이고, 가격은 Mtok당 입력 $2, 출력 $10, 캐시 읽기 $0.20입니다. auto mode에서 작업 디렉터리 밖의 파일을 읽으려 할 때 뜨는 확인 창에 '예, 하지만 다음에 다시 물어보기' 선택지가 생겼어요. 그래서 이번 한 번만 허용하고 다음 읽기 때는 다시 확인받을 수 있습니다. /usage와 상태 표시줄에서는 Claude apps gateway 지출 한도를 '$271.40 / $500.00 spent this month'처럼 금액으로 보여 줘요. 단, gateway도 이 버전 이상이어야 하고, 상태 표시줄의 rate_limits.spend_limit에는 used_usd, limit_usd, period 필드가 새로 들어갔습니다. 이 밖에 keybindings.json에서 /effort 슬라이더 키를 바꿀 수 있는 effortSlider:decreaseEffort, increaseEffort, toggleUltracode 액션이 추가됐어요. claude.ai 구독자는 /help와 명령 메뉴에서 /rate-limit-options를 찾을 수 있고, 대화형 터미널에서 쓸 수 있는 /mcp reconnect all도 새로 들어갔습니다.
