3.20.0 버전이 2026-09-28에 릴리스됐어요. 새 기능으로는 api에 Agents 자격 증명(credential)·세션 옵션이 추가됐고(#3967), Responses에 Cyber access programs가 들어갔어요(#3956). responses 쪽은 WebSocket 텍스트와 도구 스냅샷을 증분 방식으로 받도록 옵트인할 수 있게 됐고(#3973), WebSocket accumulator의 상세 스냅샷도 보존돼요(#3981). 버그 수정은 대부분 WebSocket 관련이에요. 매핑되지 않은 TLS 전송 오류를 클라이언트가 재시도하고(#3982), live에서는 소수점 단위 transcript grouping 데드라인에서 멈추던 문제(#3970)와 쿼리 파라미터가 WebSocket 엔드포인트 경로에 섞이던 문제(#3972)가 고쳐졌어요. 그 밖에 realtime WebSocket 업그레이드 때 base URL 쿼리를 보존하도록 바뀌었고, live·realtime 모두 이미 시도한 전송을 다시 보내는 불확실한 재전송을 막도록 수정됐어요(#3971, #3978, #3980). 잡무(Chores)로는 batch, files, uploads 등의 API 오류 응답 문서화가 보강됐어요.
