OpenAI가 새 모델 GPT-6.1 Sol을 공개했어요. 코딩, 컴퓨터 사용(computer use), 전문 업무에서 Astra에 가까운 수준의 지능을 낸다고 소개하고 있어요. 가격은 Astra 표준 API 입력·출력 토큰 가격의 5분의 1이에요. 그래서 Astra급 성능이 필요하지만 API 비용이 부담스러웠던 개발자라면 한번 살펴볼 만해요. 아직 본문이 제공되지 않아서 구체적인 벤치마크나 사용 방법은 원문에서 확인해야 해요.
