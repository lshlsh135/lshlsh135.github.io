Claude Code v2.1.285에서는 CLAUDE_CODE_DISABLE_WEB_FETCH 환경 변수가 추가됐어요. 이걸 설정하면 WebFetch 도구를 끌 수 있고, 비스트리밍 fallback 요청이 타임아웃 났을 때 재전송 횟수를 제한하는 CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES도 새로 들어왔어요. claude --desktop 명령으로 현재 디렉터리를 Claude 데스크톱 앱에서 바로 열 수 있고, --continue나 --resume <id>를 붙이면 기존 세션을 이어서 열 수 있어요. 플러그인 쪽에서는 claude plugin configure <plugin>으로 플러그인 옵션과 아직 값이 비어 있는 항목을 확인할 수 있어요. --values-stdin을 주면 stdin으로 새 값을 저장할 수 있고, claude plugin install --config에 <server>.<key>=<value> 형식을 넘겨서 번들된 .mcpb MCP 서버 설정을 설치할 때 바로 지정할 수도 있어요(/plugin → Configure를 따로 거치지 않아도 돼요). 조직 관리자라면 allowedProviders 관리형 설정으로 머신마다 쓸 수 있는 API 제공자를 제한할 수 있어요. Anthropic API, 커스텀 엔드포인트, Bedrock, Mantle, Vertex AI, Foundry, Claude Platform on AWS, Cloud gateway 중에서 고르면 돼요.
