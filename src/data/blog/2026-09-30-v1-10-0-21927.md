2026-09-30에 v1.10.0이 나왔어요 (v1.9.0 → v1.10.0). 이번 버전은 Admin API 쪽 추가가 많아요. Claude Enterprise 분석, 지출 한도(spend limits), RBAC 그룹·역할이 들어갔고, 사용자별 사용량·비용 리포트와 Plugins·Plugin Marketplaces 관리, 플러그인의 조직 전체 설치 설정 제거도 지원해요. Managed Agents에서는 세션 idle 이벤트에 refusal stop reason과 stop_details가 붙고, 세션 에러에 저장소(repository) 에러 타입이 추가됐어요. MCP tunnels 베타에서는 Tunnel에 읽기 전용 transport 객체가 생겼고, 생성 응답에서 일회용 relay 토큰을 돌려줘요. Organization API 엔드포인트도 이번에 GA가 됐어요. 버그 수정도 짚어둘 게 있어요. memory store의 description, metadata, archived_at이 필수 필드로 바뀌었고, admin 플러그인 설정·마켓플레이스 필드가 enum으로 타입 지정됐어요. 그룹이나 다른 사용자가 쓸 수 있는 credentials 설정 파일은 이제 거부하니까, 업그레이드 전에 파일 권한을 확인해 보세요.
