Claude Code v2.1.286에서는 여러 개의 권한 요청이 한꺼번에 쌓이면 권한 프롬프트에 "2 of 5"처럼 몇 번째 요청인지 개수가 표시돼요. 전체 화면 모드에서는 목록의 "N more" 행을 마우스로 클릭해서 목록 끝으로 바로 이동할 수 있고, 마우스를 올리거나 눌렀을 때 상태 표시도 나와요. 버그 수정도 여러 개 들어갔어요. gcpAuthRefresh나 awsAuthRefresh 자격 증명이 만료됐을 때 Claude Code 프로세스와 IDE 확장이 각자 로그인 브라우저를 여는 문제가 고쳐졌어요. 이전 세션이 크래시 나거나 강제 종료된 경우 병렬 도구 호출 뒤에 claude --resume이나 --continue가 대화 턴을 전부 잃어버리던 문제도 고쳐졌어요. 도구나 훅이 텍스트 대신 객체, 숫자, 불리언을 반환하면 API 400 에러가 나던 문제(재개한 세션 포함)가 해결됐고, 기록이 아주 긴 클라우드 세션이 깨어나지 않던 문제와 Claude apps gateway 지출 측정기에서 1시간 프롬프트 캐시 쓰기를 5분 요금으로 계산하던 문제도 수정됐어요.
