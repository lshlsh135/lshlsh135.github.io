2026-09-30에 나온 3.22.1 패치 릴리스로, 새 기능 없이 버그 수정과 문서 정리 위주예요. api 쪽에서는 인증 정보가 없을 때 나오는 에러 메시지가 제대로 나오도록 고쳤고(#3993, closes #3962), NotRequired로 선언된 TypedDict 필드도 올바르게 변환되도록 수정됐어요(#3995). 테스트 쪽에서는 sample_file.txt를 LF 줄바꿈을 쓰는 텍스트 파일로 지정했어요(#3879). 문서에서는 예제 주석 두 개가 오래된 내용이라 고쳤고(#3877), 스트리밍 헬퍼 문서 예제가 event.delta를 출력하도록 바뀌었어요(#3876). 인증 에러 메시지나 NotRequired 필드 처리 때문에 문제를 겪었다면 업데이트해 볼 만해요.
