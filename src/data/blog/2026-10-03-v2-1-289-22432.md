Claude Code v2.1.289는 버그 수정 중심 패치다. 복합 셸 명령어의 중첩 부분에 설정된 deny/ask 규칙이 사용자 설치 mod의 승인에 의해 무시되던 문제와, 닫히지 않은 `<script>` 태그가 많거나 `${` 중첩이 깊은 짧은 코드 블록에서 터미널이 멈추던 문제가 수정됐다. 심볼릭 링크를 통해 @-멘션되거나 IDE에서 선택된 파일에 Read deny 규칙이 적용되지 않던 보안 관련 버그도 잡혔다. VSCode 환경에서는 v2.1.288에서 도입된 `claude auth status` 변경이 롤백됐는데, 해당 변경이 로그아웃을 더 자주 유발할 수 있었기 때문이다. 플러그인 관련 수정도 다수 포함됐다: 로컬 폴더 마켓플레이스에서 설치한 플러그인이 `plugin list`, `plugin eval`, `plugin update` 명령에서 구버전으로 표시되던 문제, `--plugin-dir` 심볼릭 링크의 핫 리로드 오작동, 업그레이드 후 첫 세션에서 설치된 mod가 로드되지 않던 문제, Background tasks 다이얼로그가 풀스크린으로 열려 있을 때 플러그인 행이 오래된 상태로 표시되던 문제 등이 수정됐다.
