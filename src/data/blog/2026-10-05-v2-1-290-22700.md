이번 v2.1.290 업데이트에서는 mod의 `turn.step` 훅 결과에 `serverToolUses`가 추가되어, advisor(API)가 직접 실행한 툴 호출 목록(id, name, input, start, end 포함)을 훅에서 바로 열람할 수 있다. 플러그인 훅의 `tool.check` 이벤트에 `agentId`가 추가되어 서브에이전트의 권한 체크와 메인 세션의 권한 체크를 구분할 수 있게 됐고, 같은 `tool.check` 훅의 question/verdict에 `ceiling` 필드도 생겨 조직이 특정 툴에 요구하는 승인 레벨을 명시적으로 확인할 수 있다. 플러그인 훅 타이핑에 `ThemeKey`·`Color` 타입이 추가됐으며, `claude plugin validate`에서 gating site에 등록된 각 훅의 `.catch` 유무를 `--json`(gatingHooks) 플래그로 출력해준다. UX 측면에서는 Claude 앱 게이트웨이 로그인 승인 페이지에 Deny 버튼이 추가되어 승인 대기 중인 터미널이 수 초 내에 종료되며, `claude attach <name>`·`claude logs <name>` 커맨드가 추가되어 세션 id 대신 이름의 일부만 입력해도 동작한다. 끝으로 `/claude-api managed-agents-onboard <url>` 커맨드가 신규 추가됐다.
