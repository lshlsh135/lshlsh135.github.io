🎯 한 줄 요약: Anthropic이 보안 전문가를 위한 Cyber Verification Program(CVP)을 3단계 접근 티어로 재편하고, 기존 Project Glasswing을 통합했다.

## 📌 무엇이 바뀌었나
- 기존 CVP와 Project Glasswing을 하나로 통합해 Defense Access / Red Team Access / Specialized Access 세 티어로 구조화했다.
- 각 티어에서 Claude Opus 5.5, Claude Sonnet 5.5, Claude Mythos 5.1 등 최신 모델을 이용할 수 있으며, 이후 신규 모델도 포함될 예정이다.
- Claude Platform, Google Cloud Vertex AI, Microsoft Foundry에서 제공되며, Amazon Bedrock은 Enterprise Frontier Safeguards(EFS) 적격 고객에게만 제공된다.

## 🛠️ 어떻게 쓰는가
Defense Access는 SOC·인시던트 대응, 악성코드 역공학, 취약점 분석·검증 등 방어 업무 전용이며 신청 후 수일 내 결과를 받을 수 있다. Red Team Access는 방어 기능에 승인된 침투 테스트와 레드팀 업무를 추가하며 심사에 수 주가 걸린다 — 현재 개인 연구자는 신청 불가, 조직 단위만 가능하다. Specialized Access는 항공 운영 시스템, 전력망, 통신망, 은행 간 결제 인프라, 정부 행정망 등 핵심 안전 시스템 테스트 기관으로 한정되며 미국 정부와 공동 심사한다. Project Glasswing 기존 회원은 이 티어로 자동 전환되어 재승인이 필요 없다.

## 💼 누가 써야 하나
기업·비영리·대학·정부 방어팀, 중소 보안 업체, 오픈소스 유지관리자, 개인 취약점 연구자(Defense Access)부터 인하우스 레드팀·침투 테스트 전문 기업(Red Team Access)까지 폭넓게 대상으로 한다.

## ⚠️ 주의사항
프로그램 등록 조직은 오남용 모니터링을 위해 데이터 보존이 필수이며, 제로 데이터 보존을 원하는 조직은 올 가을 출시 예정인 EFS를 기다려야 한다. Red Team Access에서도 랜섬웨어 배포, 물리적 시스템 손상, 고위험 안전 시스템 침투 테스트는 실시간으로 차단된다.
