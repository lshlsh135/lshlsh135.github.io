Claude Code v2.1.292가 릴리스됐다. `claude plugin install`에 `--marketplace <source>` 플래그가 추가되어, 마켓플레이스 등록과 플러그인 설치를 한 번에 처리할 수 있게 됐고, Agent 도구에 `effort` 파라미터가 생겨 서브에이전트를 원하는 노력 수준으로 실행할 수 있다. 529(과부하) 응답 재시도 시 기본 딜레이를 조정하는 환경변수 `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`도 추가됐다. 모드(mod) 개발자에게는 두 가지 새 API가 생겼는데, `prompt.autocomplete` 이벤트로 프롬프트 입력창 자동완성 목록에 항목을 추가할 수 있고, `$.model.complete`의 `prompt`·`system` 블록에 `cache: true`를 설정해 프롬프트 캐싱을 활용할 수 있다. 또한 `agent.spawn` 훅에 워크플로우 에이전트 정보(`run`, `index`)가 전달되어 모드가 특정 에이전트 실행을 거부하는 것도 가능해졌다. 버그 픽스로는 `permissionMode: auto`가 설정됐을 때 auto 모드를 지원하지 않는 환경에서 잘못 진입하던 문제가 수정됐다.
