Anthropic SDK v3.25.0(2026-10-06)이 출시됐다. 에이전트 관련 변경이 핵심으로, 로컬 툴 실패를 관찰(observe)할 수 있게 됐고(#4028), 스트리밍 세션 생성 중에도 로컬 툴을 실행할 수 있게 됐다(#4027). API 쪽에서는 에이전트 턴 아이템과 사용량 소스 그룹핑이 추가됐으며(#4030), 라이브러리에서 `type_to_response_format_param`을 퍼블릭으로 익스포트한다(#2993). 툴 검색에서 `defer_loading=True` 옵션을 타입드 함수 헬퍼에서도 지원하게 됐다(#4029).
