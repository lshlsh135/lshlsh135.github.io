Anthropic 공식 SDK가 v1.12.0으로 업데이트됐다(2026-10-07). 신규 모델 `claude-haiku-5-5`가 API에 추가됐고, typed computer 및 browser toolset 툴 호출도 지원된다. API 쪽에는 RBAC 역할에 `display_name` 필드가 생기면서 기존 `name` 필드가 deprecated 처리됐고, `/v1/models` 엔드포인트에 lifecycle 단계 필드와 필터가 추가됐으며 Managed Agents의 `web_fetch` 툴 설정에 `url_sources`도 들어왔다. 버그 픽스로는 spend limit 조회 시 beta 헤더가 기본 전송되도록 수정됐고, 메모리 업로드 응답 유실 후에도 로컬 편집이 보존되는 문제가 해결됐다. RBAC `name` 필드를 직접 참조하는 코드가 있다면 `display_name`으로 마이그레이션이 필요하다.
