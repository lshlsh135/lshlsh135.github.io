Claude Code v2.1.293의 핵심 변경은 Haiku 5.5(`claude-haiku-5-5`) 추가로, Anthropic API의 기본 Haiku 모델이 교체됐다. 컨텍스트 윈도우는 100만 토큰이며 가격은 입력 $0.10/출력 $0.50 per Mtok(프롬프트가 100K 초과 시 $0.50/$2.50)이다. 서브에이전트 쪽에서는 `subagentStatusLine` 페이로드에 `agentType`이 추가돼 커스텀 서브에이전트 타입을 스크립트에서 구분할 수 있고, `$.tool.register`에 `isDeferred` 옵션이 생겨 `false`로 설정하면 툴 스키마를 툴 검색 뒤가 아닌 프롬프트 시작부터 노출할 수 있다. 버그 수정으로는 컨텍스트 압축 직전 작업을 압축 후 '이미 완료'로 착각해 재실행하는 오류, HTTP MCP 연결에서 요청이 누적되던 메모리 누수, `←` 키로 세션을 백그라운드로 옮길 때 메시지가 유실되던 문제(이동 불가 시 `←` 키가 고정되며 알림 표시), `/model` 화면의 노력 수준 화살표 키가 최고·최저 수준을 넘어 순환되며 잘못된 기본값을 저장하던 문제, Chrome에서 `/tui` 사용 중 연결이 끊기던 문제(발생 조건 일부가 EXCERPT에서 잘림) 등이 수정됐다.
