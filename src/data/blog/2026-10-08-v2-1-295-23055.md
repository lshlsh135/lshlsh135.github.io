Claude Code v2.1.295에서 커맨드/HTTP 훅에 `onFailure: "block"` 옵션이 추가되어, 훅이 시작 실패·타임아웃·비정상 종료될 경우 해당 액션을 통과시키는 대신 차단할 수 있게 됐다. OSC 7501(Program Status Protocol) 지원이 추가되어 이 프로토콜을 구현한 터미널에서 Claude Code가 현재 작업 중인지, 사용자 입력을 기다리는지, 완료됐는지 상태를 직접 표시할 수 있다. `/copy` 피커에서 초안 메시지를 복사할 때 `>` 인용 마커가 자동으로 제거되며, `claude -p` 실행 후 마지막 턴이 끝나도 프로세스가 열려 있을 경우 무엇을 기다리는지 stderr에 출력해 준다. Bedrock·Vertex·Foundry 등 클라우드 업스트림 연결에서는 `timeouts.upstream_ttfb_ms` 값으로 스트림 첫 바이트 응답 대기 시간을 제한할 수 있고, 초과 시 페일오버 또는 502를 반환한다. 플러그인 install·enable·disable 및 마켓플레이스 add 명령 실행 시 쓰기 대상 설정 파일이 로드되지 않는 상태이면 경고가 표시된다.
