v1.13.0 업데이트에서는 API에 Chat 및 Cowork 통합 분석 지표(unified analytics metrics) 타입이 추가됐다. Managed Agents 쪽에서는 workflows 설정, 멀티에이전트 구성(multiagent configuration), 그리고 스레드 상태 필터링(thread status filtering) 기능이 새로 지원된다. 내부적으로는 기본 API 버전 헤더 값에 이름이 부여되는 정리 작업도 포함됐다.
