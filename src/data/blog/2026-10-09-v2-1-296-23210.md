Claude Code v2.1.296에서 Claude Desktop 게이트웨이 모드 관련 관리 설정이 확장됐다. `managed.policies[]`에 `code` 키가 추가돼 CLI와 동일한 설정을 Claude Desktop의 Code 탭에도 적용할 수 있고, 이 키를 사용하면 Claude Desktop의 게이트웨이 모드도 함께 활성화된다. 서브에이전트 frontmatter와 `--agents` 정의에 `autoCompactWindow`가 추가돼 서브에이전트가 메인 대화 창보다 더 일찍 자동 압축을 트리거할 수 있다. 워크플로 내 모든 에이전트를 특정 단일 모델로 실행하고 싶을 때 쓰는 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` 환경변수와, 과부하(529) 요청 재시도 시 백오프 최대 대기시간을 늘릴 수 있는 `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` 환경변수도 새로 생겼다. Read 도구에 `allow_large` 옵션이 추가돼 컨텍스트 여유가 있을 경우 기존 크기 제한을 초과하는 텍스트 파일도 한 번에 읽을 수 있으며, 같은 이름의 플러그인이 중복 활성화됐을 때 훅이 누락되는 상황에 대한 `/plugin` 경고 메모와 `PreToolUse` 훅에서 `"continue": false`로 거부가 올바르게 동작하지 않던 버그 수정도 포함됐다.
