2026-10-09에 배포된 v3.28.0의 주요 신기능은 API에 에이전트 환경의 일시 중단(suspension)과 만료(expiration) 기능 추가(#4046)다. 이를 통해 실행 중인 에이전트 환경을 명시적으로 정지하거나 만료 처리하는 흐름을 API 레벨에서 제어할 수 있게 됐다. 의존성 변경으로는 astral-sh/setup-uv가 10.1.0→10.2.0으로, CodeQL init/analyze가 4.38.2로 각각 업데이트됐으며, PyJWT 보안 제약이 2.14.0으로 상향 고정됐다.
