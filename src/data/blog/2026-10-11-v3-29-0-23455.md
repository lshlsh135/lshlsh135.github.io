v3.29.0(2026-10-11)은 API 레벨의 소규모 기능 추가와 문서 정비가 중심인 릴리스다. 기능 면에서는 세션 오류 코드에 `billing_not_active`가 새로 추가됐고, 실시간 음성 기능의 네임드 Live 보이스 목록에 'shida'가 포함됐으며, Vault에 업데이트 및 메타데이터 필터 기능이 붙었다. 또한 베타 API의 페이지네이션 한도와 non-null 파라미터 정의가 정렬됐다. 문서 쪽에서는 Decision 생성·선택지 제약 조건, 128자 안전 식별자, Files API 속도 제한 응답 등에 대한 설명이 보강됐다. 코드 변경보다 API 스펙 명확화에 더 많은 비중이 실린 패치성 버전이다.
