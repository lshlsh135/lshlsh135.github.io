Anthropic SDK v1.14.0이 출시됐다. 가장 눈에 띄는 신기능은 API 호출·스트리밍·툴 실행 전반에 걸쳐 OpenTelemetry 트레이싱이 클라이언트에 추가된 것으로, 프로덕션 관측가능성(observability) 파이프라인에 SDK를 연결할 수 있게 됐다. Managed Agents API에는 `execution_identity` 필드가 추가됐고, Admin API에 텔레메트리 대상(destination) 관리 엔드포인트와 테스트 엔드포인트도 새로 생겼다. 스트리밍 쪽 버그도 두 건 수정됐는데, `message_start` 이전 이벤트 수신 시 "Unexpected event order" 예외를 더 이상 던지지 않고, 알 수 없는 이벤트 타입도 메시지 스트림 헬퍼를 통해 그대로 통과하도록 바뀌었다. 문서도 함께 정비되어 프리필(prefill)·thinking·폴백 동작 설명이 교정됐고, managed 역할 부여에 필요한 스코프와 user spend limit의 `is_enabled` 동작이 명확해졌다.
