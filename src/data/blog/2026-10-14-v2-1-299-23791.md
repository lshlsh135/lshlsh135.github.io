Claude Code v2.1.299이 출시되었다. 가장 주목할 변경은 유휴 압축(idle compaction) 기능으로, 200K 토큰 이상의 대화가 약 54분 방치되면 1시간짜리 프롬프트 캐시 만료 전에 자동 압축되어 다음 메시지 재처리 비용을 줄여준다(v2.1.290 이상 필요, `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`로 임계값 조정, settings.json의 `"idleCompaction": false`로 비활성화 가능). `CLAUDE_CODE_DISABLE_FILE_MENTIONS` 환경변수를 활성화하면 @파일 멘션 시 파일 내용이 아닌 경로만 Claude에게 전달되어 파일 도구로 직접 읽도록 위임할 수 있다. Managed settings로 설치된 모드에는 `$.prompt.media`(첨부 이미지·문서 바이트 접근)와 `$.session.identity()`(세션 로그인 방식·조직·이메일 조회)가 새로 추가되었다. UI 컴포넌트 측에서는 Text에 size, weight, mono, tabular 속성이, Box에 xs~xl 명명 간격 단계가 추가되었으며, bold는 deprecated 처리되었다.
