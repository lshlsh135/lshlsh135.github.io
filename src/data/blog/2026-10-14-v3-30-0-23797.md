v3.30.0이 2026-10-14에 릴리즈됐다. 신규 기능으로 베타 단계의 세션별 지출 한도(session spending limits) API, OCI 외부 스토리지 프로바이더 연동, 조직 단위 Decisions 사용량 리포팅이 추가됐다. 이미지 관련 API도 보강되어 이미지 도구 오류·모더레이션 세부 정보 노출, 이미지 URL 직접 지원, 안전 경보 설명 상세화가 포함됐고, 프로젝트 API 키 만료일 업데이트도 지원한다. 버그 픽스로는 스트리밍에서 비동기 HTTP/1.1 연결 재사용이 복구됐다.
