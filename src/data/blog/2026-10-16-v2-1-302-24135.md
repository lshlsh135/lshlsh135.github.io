Claude Code v2.1.302가 출시됐다. 클라이언트 측 자동 모드 분류기에 사용할 모델을 직접 지정하는 환경 변수 `CLAUDE_CODE_AUTO_MODE_MODEL`이 추가됐고, `/config`에 idle compaction 켜기/끄기 토글 항목도 생겼다. 독립형 서비스인 claude.ai/design(Claude Design)이 2026년 12월 14일에 종료된다는 안내가 `/design-sync` 및 `/design-login` 명령 실행 시 표시된다. 버그 수정도 여러 건 포함됐는데, 대화 압축 중 턴을 중단할 때 발생하던 "Prompt is too long" 오류, 세션 도중 Vertex 또는 Bedrock으로 전환 후 나타나던 "diagnostics: Extra inputs are not permitted" 오류, Read 도구가 대용량 이미지 파일 전체를 메모리에 올리던 문제(이제 128 MB 초과 이미지는 거부)가 수정됐다. 또한 `anthropic/claude-opus-4-1`처럼 게이트웨이가 Opus 4 또는 4.1에 접두사를 붙일 경우 `/autocompact`·`/effort`가 잘못된 모델로 저장되던 문제도 패치됐다.
