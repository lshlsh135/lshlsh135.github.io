2026-10-16에 공개된 v3.32.0은 API SDK 업데이트로, Live 세션에서 오디오 픽스처 재생과 Decisions 지원이 새로 추가됐다. 캐시 설정 및 키 옵션(2/2단계 완료), 프롬프트 기반 음성 생성, 지역별 데이터 처리 레지던시 옵션도 이번 버전에 포함됐다. 응답 오류 진단 및 모델 공지 기능이 생겨 디버깅이 더 편해졌고, Realtime 응답 오류 메시지 선언 버그도 수정됐다. 내부적으로는 WebSocket 연결 처리 코드가 리팩터링됐다.
