2026-10-17에 v3.34.0이 릴리즈됐다. 이번 버전에서는 두 가지 API 기능이 추가됐는데, 하나는 외부 스토리지가 저하(degraded) 상태일 때 이를 감지할 수 있는 상태 API(#4097)이고, 다른 하나는 실시간 번역을 위한 WebSocket 세션 API(#4095)다. BODY가 제공되지 않아 상세 사용법은 공식 릴리즈 노트를 직접 확인해야 한다.
