Claude Code v2.1.304 릴리즈다. 플러그인 개선으로, 먼저 실행되는 플러그인이 mod의 훅을 건너뛸 때 트랜스크립트에 해당 이벤트와 플러그인 이름이 표시된다. mod의 `tool.check` 응답에 `decider: "person"`을 지정하면 권한 대화상자나 호스트 콜백만 승인할 수 있고, 아무도 승인할 수 없는 상황에서는 mod의 reason과 함께 자동 거절된다; 아울러 `e.isReadOnly` 필드가 추가돼 읽기 전용 툴 호출인지 tool.check 이벤트에서 바로 확인할 수 있다. 신규 커맨드 `/auto-mode-setup`은 현재 프로젝트와 최근 세션을 읽어 auto mode 환경을 안내형으로 세팅해주며, Bedrock·Vertex·Foundry·Claude apps gateway·텔레메트리 비활성 세션에서도 사용 가능하다. `/claude-api managed-agents-secure`는 Managed Agents 에이전트 설정을 Anthropic 공개 보안 가이드와 비교 분석해주는 읽기 전용 커맨드로, 설정 변경은 없다. 트랜스크립트 뷰(Ctrl+O) 압축 요약에 이전에 호출된 툴 이름도 함께 표시되며, Pro·Max 플랜에서 비활성 대화 재개 시 컨텍스트 소비가 클 경우 경고 안내가 뜬다.
