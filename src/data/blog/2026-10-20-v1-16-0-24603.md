v1.16.0에서는 User Profiles가 정식(GA) 출시되었고, Admin API에 워크스페이스 레이트 리밋 업데이트 기능이 추가되었다. 애널리틱스 리포트 페이지 API에는 `data_refreshed_at`과 `has_more` 두 필드가 새로 생겼고, google-cloud 모듈은 v1 엔드포인트로 전환하면서 organization 엔드포인트도 추가됐다. 클라이언트 쪽에서는 미인식 이벤트 이름을 가진 서버-전송 이벤트(SSE)도 그대로 yield하도록 동작이 바뀌었다. 문서 보강도 상당한데, Managed Agents API의 자격증명 만료·vault·메모리 스토어 설명이 개선되고, Messages API 요청 설명과 플러그인 `manifest_version` 및 `reach` 항목 설명도 수정됐다.
