Claude Code v2.1.305가 릴리스됐다. 신규 기능으로는 Linux 샌드박스 환경에서 `sandbox.allowNestedUserNamespaces`를 켜면 Chromium이나 rootless podman 같은 도구가 user namespace를 생성할 수 있게 됐고, 무인 재시도 모드(`CLAUDE_CODE_RETRY_WATCHDOG`) 사용 시 사용량 한도 해제를 reset 전에 감지하는 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` 환경 변수도 추가됐다. 2.1.304에서 도입된 회귀 버그도 수정됐는데, Vertex·Bedrock 등의 엔드포인트나 게이트웨이가 tool search를 거부할 경우 모든 요청이 실패하던 문제로, 이제 ToolSearch 없이 재시도하는 방식으로 처리된다. 그 외에 `/effort`·`/autocompact` 설정이 `modelOverrides` 값과 대소문자 차이나 `[1m]` 태그 유무로 인해 적용되지 않던 버그, bare 저장소에서 새 worktree가 기본 브랜치 대신 로컬 HEAD에서 시작하거나 변경 없는 서브에이전트 worktree가 정리되지 않던 문제, 디스크 포화 시 Bash 명령이 raw ENOSPC 경로 오류로 실패하던 문제도 함께 잡혔다.
