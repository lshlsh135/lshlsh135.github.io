Anthropic SDK v2.0.0이 출시됐으며 파괴적 변경(breaking changes)이 포함되어 있다. 가장 큰 변화는 새 API 버전 2026-10-21 지원 추가로, 기존 코드와 호환성을 확인해야 한다. 지출 한도 목록 조회(list spend limits) API에 `workspace_id` 필터와 `usage_tier` 스코프 타입이 새로 추가됐다. 문서 측면에서는 메시지 설명에서 오래된 system 역할 관련 주석이 제거됐다.
