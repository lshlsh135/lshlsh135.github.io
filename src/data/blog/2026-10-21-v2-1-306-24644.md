Claude Code v2.1.306이 출시됐다. 이번 패치는 버그 픽스 두 가지로 구성된다. 첫 번째는 클라우드 세션 안에서 `claude -p`를 실행할 때 세션 환경 변수 없이 시작하면 "Not logged in" 오류가 뜨던 문제를 수정했다. 두 번째는 MCP 툴이 많은 세션에서 실제 API 에러가 "prompt is too long" 메시지로 덮어써지고 불필요한 컨텍스트 압축(compaction)이 추가로 발생하던 문제를 고쳤다.
