Claude Code v2.1.307이 릴리스됐다. 신규 기능으로는 `/claude-api api-version` 명령으로 Claude API 코드를 API 버전 2026-10-21로 전환하는 기능, 그리고 권한 규칙·오토 모드·안전 체크·훅·샌드박스가 툴 호출을 차단·프롬프트·반환할 때마다 `claude_code.safety_event` OpenTelemetry 이벤트를 기록하는 기능이 추가됐다. 버그 수정 측면에서는, `CLAUDE_CODE_DISABLE_1M_CONTEXT` 환경 변수가 설정된 상태에서 `opus[1m]` 같은 `[1m]` 접미사 모델 별칭을 쓸 때 model-not-found 오류가 나던 문제가 고쳐졌다. 커스텀 `ANTHROPIC_BASE_URL` 게이트웨이나 Foundry 환경처럼 효과가 없는 곳에도 `prompt-caching-scope` 베타 헤더가 계속 전송되던 문제도 수정됐다. macOS에서 로그인 키체인이 잠긴 채로 `claude -p`를 실행하면 MCP 서버가 무조건 "needs authentication"으로만 표시되던 문제도 잡혔고, 이제 잠금 해제 후 재로그인 없이 바로 연결된다. 마지막으로 macOS·Linux 슬립 중 MCP 서버가 타임아웃으로 잘못 보고돼 헤드리스 실행에서 계속 failed 상태로 남던 문제와, 연결 끊김 시 HTTP MCP 툴 호출이 두 번 전송되던 문제도 함께 수정됐다.
