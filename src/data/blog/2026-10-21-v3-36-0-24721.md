Anthropic Python SDK v3.36.0(2026-10-21)이 출시됐다. 신기능으로는 Responses API에 Vertex AI 지원이 추가됐고, 30분 단위 cache-write 사용량 카운팅, 컴팩션 트리거 ID, 커스텀 음성 동의 관리, 네이티브 동기 WebSocket 옵션 타입이 들어왔다. 버그 픽스는 WebSocket 쪽에 집중됐는데 복구·취소 시 close 유지, 네이티브 옵션 미반영 문제, 레거시 Beta Realtime 연결의 클라이언트 헤더 보존 등 9건이 수정됐다. Pydantic v1 validation에서 declared aliases가 날아가는 문제와 Vertex API root가 response lifecycle에서 누락되는 문제도 함께 잡혔다.
