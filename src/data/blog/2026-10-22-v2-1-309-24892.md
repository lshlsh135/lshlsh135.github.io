Claude Code v2.1.309는 샌드박스 및 권한 검사 관련 버그 수정에 집중한 패치 릴리스다. macOS·Linux에서 샌드박스 Bash 명령이 샌드박스 밖에서 쉘 시작 파일을 실행하던 문제, macOS의 denyWrite 글로브 패턴이 심링크를 통해 접근한 실제 경로에 적용되지 않던 문제가 수정됐다. --mcp-config로 전달한 MCP 설정 파일을 샌드박스 명령이나 자동 승인된 편집으로 수정할 수 있었던 보안 허점도 막혔고, 비활성화된 MCP 서버가 print·SDK 세션의 권한 프롬프트 때 다시 연결되는 오동작도 고쳐졌다. 그 외 리디렉트 실패 가능성이 있는 명령에서 변수를 신뢰하던 Bash 권한 검사 문제, cd가 래핑·접두 처리된 일부 복합 명령에서 git 실행 전 디렉터리 변경이 권한 프롬프트를 우회하던 문제, 서브쉘을 포함한 명령에서 Edit(path) 차단 규칙이 Bash 리디렉트를 막지 못하던 문제, 워크트리 격리 세션이 로케일 접두어가 붙은 일부 명령을 허용하던 문제도 수정됐다.
