v3.36.1이 2026-10-22에 릴리스됐다. 버그 수정으로는 API 호출별 WebSocket 쿼리 설정이 실제로 적용되지 않던 문제(#4138), 녹음 사이에 마이크 캡처가 중단되지 않던 문제(#4143), 브라우저 드라이버 상태를 읽기 전에 브라우저 호출 유효성을 검사하지 않던 문제(#4142)가 각각 패치됐다. 문서/코드 정리 차원에서는 서비스 계정 API 키 삭제 관련 설명이 보강됐고(#4151), 내부 리팩터링으로 청크 업로드 런타임(#4146)과 벡터 스토어 폴링 런타임(#4148)이 수작업 구현 방식으로 전환 준비됐다.
