Anthropic Python SDK가 v2.2.0으로 업데이트되며 메시지 스레드(message threads) API 지원이 새로 추가됐고, 차원별 사용량·비용 리포트 API도 신규 도입됐습니다(기존 리포트 엔드포인트는 legacy로 표시). tool runner 관련 버그가 여러 건 수정됐는데, append_messages() 호출 후 히스토리를 caller에게 올바르게 넘기지 못하던 문제, set_messages_params() 콜백이 tools를 definitions 형태로 받지 못하던 문제, 콜백이 tools 목록을 줄였을 때 제거된 툴이 계속 실행되던 문제, 그리고 set_messages_params()가 betas·user_profile_id·workspace_id를 누락했을 때 tool runner가 이를 잃어버리던 문제 등이 포함됩니다. max_retries 에러 메시지에서 math.inf를 권장하던 표현도 제거됐습니다. 문서 쪽에서는 plugin 콘텐츠 스캔 설명, served_version_pinned·updated_at 설명, 사용량·비용 리포트 예시와 ending_at 설명, 그리고 모델 목록 레이트 리밋이 조직·워크스페이스별로 다르다는 점이 정정·보완됐습니다.
