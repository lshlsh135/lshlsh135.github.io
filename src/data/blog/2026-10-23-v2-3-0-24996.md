Anthropic SDK v2.3.0이 릴리스됐다. 가장 눈에 띄는 신기능은 Claude Enterprise 조직을 위한 Claude Tag 엔드포인트 API가 추가된 것이다. 버그 수정으로는 google-cloud에서 사용자 프로필 요청이 올바른 조직 엔드포인트로 전송되지 않던 문제가 해결됐다. 내부적으로는 엔드포인트 경로에 하드코딩되어 있던 쿼리 파라미터 전송 방식을 정리하고, beta 관련 쿼리 파라미터 처리 로직도 개선됐다. 문서 측면에서는 MCP async tool_runner 예제의 불필요한 await 제거, Bedrock·Vertex raw response 독스트링에 SDK 문서 링크 추가, 코드 실행 툴 및 암호화 결과 설명 개선 등이 포함됐다.
