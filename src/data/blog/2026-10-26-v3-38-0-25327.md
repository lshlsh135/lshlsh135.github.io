2026-10-25 배포된 v3.38.0에서 API에 위임 제어(delegation controls)와 프롬프트 캐시 수명(prompt cache lifetimes) 설정 기능이 추가됐다. Live Decision 아이템 및 질문 타입도 확장됐다. 버그 수정 측면에서는 응답 함수 인수를 올바른 네임스페이스 안에서 해석하도록 수정하고, 러너 디스패치 전 툴 네임스페이스 유효성 검사를 추가했으며, PEP 604 유니온 타입 파싱 폴백도 복구됐다. API 상태 에러는 이제 서버 메시지를 그대로 포매팅해서 보여준다. 내부적으로는 생성된 Python 파일에 커스텀 코드가 섞이지 않도록 강제하는 규칙도 적용됐다.
