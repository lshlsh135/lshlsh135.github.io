Claude Code v2.1.312가 출시됐다. OIDC 설정에 `oidc.user_id_claim` 옵션이 추가돼, Microsoft Entra ID의 `oid`처럼 `sub` 이외의 id_token 클레임으로 사용자를 식별할 수 있게 됐다. 풀스크린 모드에서 대기 중인 메시지 아래의 "to send now" 힌트를 클릭하면 즉시 전송되는 기능도 추가됐다. 버그 수정으로는 VS Code 익스텐션에서 로그인 후 관리형 설정·조직 정책이 세션 내내 불러와지지 않던 문제, 하위 디렉터리의 대용량 CLAUDE.md나 @-포함 파일을 일부만 읽은 뒤 덮어쓰던 문제(Write가 전체 읽기 또는 편집 방식으로 동작하도록 변경), git 저장소 안에서 Bash `cd`로 더 깊은 디렉터리로 이동한 뒤 per-directory 스킬이 인식되지 않던 문제, 터미널 세션 재개 후 첫 응답이 다음 재개 시 사라지던 드문 버그, 잘못된 이름의 커맨드 하나 때문에 모든 커맨드 로딩이 중단돼 `claude -p`가 출력 없이 종료되던 문제, Read 도구가 PDF에서 간헐적으로 실패하던 문제 등이 수정됐다.
