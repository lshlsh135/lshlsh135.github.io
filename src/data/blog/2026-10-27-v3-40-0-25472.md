2026-10-27 릴리스된 anthropic Python SDK v3.40.0의 핵심 변경은 프롬프트 캐시 브레이크포인트에 TTL(Time-To-Live) 옵션을 지정할 수 있게 된 것이다(PR #4188). 기존에는 캐시 브레이크포인트의 만료 시간을 제어할 수 없었는데, 이번 업데이트로 세밀한 캐시 수명 관리가 가능해졌다. 버그 픽스로는 브라우저 데모 의존성을 명시적으로 지정하는 CI 수정(PR #4185)이 포함됐고, 내부적으로는 생성 코드(generated-code) 분리 완료 기록 및 SDK 헬퍼 보존 작업(PR #4186, #4190)도 함께 들어갔다. 그 외 griffe 1.14.0→2.3.0, GitHub Actions 관련 deps 다수 버전업 등 의존성 정리가 이뤄졌다.
