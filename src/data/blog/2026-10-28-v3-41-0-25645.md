v3.41.0(2026-10-28)에서 Realtime response inputs에 typed references를 넣을 수 있게 됐고, response tool usage models가 새로 추가됐다. metadata를 기준으로 agent sessions를 필터링하는 API도 생겼으며, WebSocket 재연결 후 큐에 남아 있던 binary frames를 자동 복구하는 기능도 포함됐다. 버그 수정으로는 불완전한 WebSocket 응답 감지와 push-to-talk 중 인터럽트·연결 끊김 처리가 개선됐다. 개발 환경에서는 타입 체크 도구를 ty로 전환했고, 곧 종료 예정인 모델 목록을 API 문서에 반영했다.
